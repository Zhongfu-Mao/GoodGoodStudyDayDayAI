# 本周结论

- 本周最清晰的主线是 **Agent 从 prompt engineering 走向 harness engineering**。
- 开源模型竞争不再只看参数规模，而是同时看许可、上下文、多模态与 coding 能力。
- 工具层最值得关注的是 OCR、本地运行、后训练框架与评测方法。

## 一周里发生了什么

## 1. Agent 系统从“会调用工具”进入“有运行时设计”

- The Anatomy of an Agent Harness、Advisor Strategy、Build Agents That Don't Fail in Production 这些内容连在一起，已经把 Agent 系统的核心模块讲得很清楚。
- 记忆、权限、恢复、上下文构造、模型路由、工作区隔离，正在替代“单条 prompt 怎么写”成为核心议题。

## 2. Claude Mythos 与 Glasswing 打开了“门控前沿模型”叙事

- Mythos 不是单纯的性能新闻，它意味着头部实验室可能会把最强能力优先放在定向合作和高风险场景中。
- 这一变化会反过来影响 API 分层、企业合作与安全研究节奏。

## 3. 开源模型和开源工具都在提速

- Gemma 4、Qwen 3.6-Plus、GLM-5.1 代表了本周最值得记住的开源模型信号。
- TRL v1.0、Transformers v5、llama.cpp OCR、Harvey 风格结构化审阅，则说明“把模型变成工作流”这件事正在越来越顺手。

## 4. 产品入口之争已经开始

- Perplexity 往金融 Agent 转，Claude for Word 进入办公入口，Hermes / OpenClaw 代表个人可控 harness，说明大家争的是下一层操作系统入口。

## 本周值得继续跟踪

- Harness Engineering 会不会成为下一个人人默认使用的工程词汇。
- 门控前沿模型是否会成为 Anthropic、OpenAI、Meta 的共同发布模式。
- 本地 OCR、多模态与结构化 extraction 会不会成为最先规模落地的 AI 工具能力。
