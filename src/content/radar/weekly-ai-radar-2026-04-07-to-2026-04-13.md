## 本期范围

- 时间窗口：2026-04-07 ~ 2026-04-13
- 覆盖日报：2026-04-07 至 2026-04-13（共 7 份）

## 本期核心研判

- **Agent 范式转移**：设计重心从 Prompt Engineering 彻底外移至 Harness、Memory、Authority 及失败恢复（Recovery）等运行时架构。
- **门控模型时代**：以 Project Glasswing 为代表，头部实验室开始实施“门控前沿模型”策略，区分公开能力与定向合作能力。
- **工具链提速**：开源模型、结构化提取及 OCR 工具的协同进化，标志着 AI 正从单纯的聊天入口深入工作流底层。

## 1. Agent 系统迈入“运行时设计（Runtime Design）”阶段

本周多篇深度文章共同勾勒出 Agent 的成熟架构分层：不再追求单一模型的“聪明度”，而是通过 **Agent Harness** 实现工具调用、工作区隔离、状态保持及权限边界的综合治理。
- **核心逻辑**：未来的 Agent 工程，提示词只是组件之一，系统竞争力的关键在于如何设计可审计、可恢复、具备强确定性执行能力的运行时环境。
- **关键参考**：[The Anatomy of an Agent Harness](https://blog.dailydoseofds.com/p/the-anatomy-of-an-agent-harness), [Advisor Strategy in Agents](https://blog.dailydoseofds.com/p/advisor-strategy-in-agents)。

## 2. 头部模型分化：“公开版”与“门控前沿版”并行

Claude Mythos 的预览与 Project Glasswing 的发布，揭示了头部实验室（如 Anthropic）发布策略的重大转向。
- **发布逻辑**：模型发布正与网络安全、责任边界及定向合作伙伴筛选深度绑定。最强前沿能力将通过更加封闭、受控的渠道（Gate）提供，而非普适性的 API。
- **行业信号**：[Project Glasswing](https://www.anthropic.com/project/glasswing) 的叙事证明，模型能力本身已成为地缘与合规博弈的一部分。

## 3. 开源模型竞争：从“刷榜单”转向“能力闭环”

Gemma 4 等开源新锐的出现，反映了开源阵营策略的调整：不再单纯卷参数规模，而是追求多模态、长上下文、结构化输出及端侧部署的“完整工程包”。
- **架构演进**：2026 年的模型架构变化已超越了简单的 Scale-up，各种注意力变体与 Diffusion LLM 的结合正重塑模型能力边界。
- **关键参考**：[Gemma 4 深度解析](https://www.latent.space/p/ainews-gemma-4-the-best-small-multimodal), [Modern LLM 中的注意力变体可视化](https://magazine.sebastianraschka.com/p/visual-attention-variants)。

## 4. 文档理解与后训练工具链的率先成熟

OCR 工具（如 llama.cpp 的 OCR 适配）、后训练框架（TRL v1.0）及 Agent 评测指标（Six Key Metrics）在本周密集落地，说明 AI 工具层正加速进入真实业务场景。
- **落地现状**：文档结构化抽取与表格评审已具备极高的实战价值，成为首批规模化落地的 Agent 应用场景。
- **关键进展**：[TRL v1.0 发布](https://huggingface.co/blog/trl-v1), [3 万篇论文的自动 OCR 实战](https://huggingface.co/blog/nielsr/ocr-papers-jobs)。

## 5. 流量入口之争：AI 时代的操作系统原型

Perplexity 的 Agent 转型、OpenClaw 的入口尝试、以及 OpenAI 的“超级 App”野心，均指向了同一个终局：谁能占领下一代 AI 操作系统的入口。
- **竞争维度**：办公软件入口（Claude for Word）、搜索入口、Agentic IDE 及个人 Harness 正展开全方位博弈。
- **行业动态**：[Perplexity 的 Agent 转型研判](https://www.therundown.ai/p/perplexity-agent-pivot-is-on-the-money), [OpenAI 的融资与超级 App 蓝图](https://www.therundown.ai/p/openai-new-122b-funding-superapp)。

## 本周值得持续追踪

- **Harness Engineering** 是否会从少数极客的术语演进为企业级 Agent 部署的通用标准。
- **门控发布（Gated Release）** 是否会成为所有头部实验室应对安全与合规压力的默认范式。
- **本地多模态与结构化提取** 是否会在 Q2 完成大规模商业化验证。
