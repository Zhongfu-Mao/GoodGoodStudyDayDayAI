# 本周范围

- 时间窗口：2026-04-07 ~ 2026-04-13
- 覆盖日报：2026-04-07、2026-04-08、2026-04-09、2026-04-10、2026-04-11、2026-04-12、2026-04-13


# 本周结论

- 本周最清晰的主线，是 Agent 设计从 prompt engineering 继续外移到 harness、memory、authority、evaluation 和 recovery。
- Claude Mythos / Project Glasswing 让“门控前沿模型”第一次被明确摆上台面，头部实验室的发布策略开始变了。
- 开源模型、OCR 工具、后训练框架和结构化 extraction 工具一起提速，说明 AI 工具层正在真正进入工作流。

## 1. Agent 系统进入“运行时设计”阶段

- **[The Anatomy of an Agent Harness](https://blog.dailydoseofds.com/p/the-anatomy-of-an-agent-harness)**、**[Extreme Harness Engineering](https://www.latent.space/p/harness-eng)**、**[Advisor Strategy in Agents](https://blog.dailydoseofds.com/p/advisor-strategy-in-agents)** 和 **[Build Agents That Don't Fail in Production](https://blog.dailydoseofds.com/p/build-agents-that-dont-fail-in-production)** 这几篇连起来看，已经把 Agent 的关键层次讲得很清楚了。
- 这一周最值得记住的，不是“某个 Agent 很聪明”，而是大家开始把问题拆成工具调用、上下文装配、工作区隔离、失败恢复、记忆持久化和权限边界。
- 这意味着后面真正要设计的，不再只是提示词，而是 runtime、approval、state 和 eval pipeline。

## 2. 头部模型开始分出“公开版”和“门控前沿版”

- **[Anthropic @ $30B ARR, Project GlassWing and Claude Mythos Preview](https://www.latent.space/p/ainews-anthropic-30b-arr-project)** 是这一周模型层最重要的信号。Claude Mythos 不只是一次性能新闻，它代表头部实验室开始认真区分“公开版能力”和“高风险定向合作能力”。
- **[Project Glasswing](https://www.anthropic.com/project/glasswing)** 的叙事也在说明，模型发布已经和网络安全、合作对象筛选、责任边界绑在一起了。
- 同期 **Muse Spark**、**Gemma 4**、**GLM-5.1 / Qwen 3.6-Plus** 等信号，则说明前沿与开源两边都在快速抬升，但发布方式越来越不对称。

## 3. 开源模型竞争从“追分数”转向“追完整能力”

- **[Gemma 4: The Best Small Multimodal Open Models](https://www.latent.space/p/ainews-gemma-4-the-best-small-multimodal)** 代表的是另一条很重要的线：开源模型不再只讲参数规模和单榜单成绩，而是开始同时竞争多模态、长上下文、结构化输出和设备端部署。
- **[A Visual Guide to Attention Variants in Modern LLMs](https://magazine.sebastianraschka.com/p/visual-attention-variants)**、**[The Anatomy of Diffusion LLMs](https://blog.dailydoseofds.com/p/the-anatomy-of-diffusion-llms)** 这些文章则提醒我们，2026 年的架构变化不只是“更大”而已。
- 换句话说，这一周开源阵营真正抛出来的问题是：下一个好模型，应该是“更高分”，还是“更完整的工程能力包”。

## 4. OCR、后训练和评测成为最先成熟的工具层

- **[Using OCR models with llama.cpp](https://huggingface.co/blog/ggml-org/using-ocr-models-with-llama-cpp)**、**[How we OCR'ed 30,000 papers using Codex, open OCR models and Jobs](https://huggingface.co/blog/nielsr/ocr-papers-jobs)**、**[Building Harvey-style tabular review from scratch, but better](https://huggingface.co/blog/isaacus/tabular-review)** 都在说明，文档理解和结构化抽取是最先落地的一波能力。
- 同时 **TRL v1.0**、**Transformers v5**、**Six Key Metrics for AI Agent Evaluation** 把另一层问题讲清楚了：模型能力够不够是一回事，能不能稳定评估、微调、落到业务里是另一回事。
- 这也是为什么这一周的工具层看起来比模型层更“接地气”，因为它们离真实工作流最近。

## 5. 产品入口之争已经开始浮出水面

- **Perplexity 的 Agent 转型**、**Hermes / OpenClaw 对比**、**Claude for Word / 办公入口**、**OpenAI superapp ambitions** 这些信号都在指向同一个问题：谁来占下一层 AI 操作系统入口。
- 这一周我们已经能看到几种不同方向同时出现：办公入口、搜索入口、个人 harness、agentic IDE。
- 从产品视角看，这比某一次榜单排名变化更重要，因为它直接决定未来用户在哪里“使用 AI”。

## 本周值得继续跟踪

- Harness Engineering 会不会从少数工程文章中的术语，变成行业通用语言。
- 门控前沿模型会不会成为 Anthropic、OpenAI、Meta 等头部实验室的共同发布范式。
- OCR、本地多模态与结构化 extraction 会不会成为第一批大规模落地的 AI 工具能力。
