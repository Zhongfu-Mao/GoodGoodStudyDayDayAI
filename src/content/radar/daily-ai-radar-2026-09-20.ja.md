- 日付：2026-09-18

## 2. モデル最前線 & アルゴリズム探索

### Anthropic が Claude を活用して生体分子モデリングを最適化：カーネル高速化と精度の境界

- 出典：The Rundown AI / Anthropic
- 日付：2026-09-17
- リンク：https://www.anthropic.com/research/claude-uplifts-biomolecular-modeling
- 要約：Anthropic の報告によると、2名の研究者の監督下で、Claude は FlashPairformer カーネルと冗長計算の最適化を通じて、30以上の生体モデルにおいてわずかな精度のトレードオフで平均約4倍の高速化を達成しました。低 VRAM モードでは単一の GPU ノードで 1万 Token を超える一部の分子システムを正確に予測できます。7万 Token を超える実行も完了はするものの、構造は依然として不正確です。計算シミュレーションの成果はウェット実験や臨床検証と同等ではありません。

### Qwen が Qwen3.8-Omni-Flash をリリース：能動的な「粗から密へ」のマルチモーダル証拠検索

- 出典：The Rundown AI / Qwen
- 日付：2026-09-18
- リンク：https://qwen.ai/blog?id=qwen3.8-omni-flash
- 要約：Qwen はマルチモーダル API モデル Qwen3.8-Omni-Flash をリリースしました。テキスト、音声・動画、および 1M コンテキストをサポートし、粗から密への能動的な証拠検索メカニズムを導入しています。OmniVideoBench における Agent モードのスコアは 67.8（静的は 63.4）で、Token 消費量は 145736 から 79117 に減少しました。ただし、モデルはすべてのベンチマークでリードしているわけではなく（一部のベンチマークでは Gemini 3.8 Flash が優勢）、オープンソース化されたのはプラグインと Harness であり、モデルの重み自体ではありません。

- 日付：2026-09-16
- リンク：https://github.com/rowboatlabs/rowboat
- 要約：Rowboat は Spaces 協調アーキテクチャを発表しました。各メンバーはローカルで動作する独立した Assistant、メモリバンク、モデル API キーを保持し、チーム間ではパブリックチャンネルやファイルを通じて共有します。Assistant が生成した結果はトリガーしたユーザーに明確に帰属し、共有ルールの変更は対応する指示まで遡って追跡可能です。ローカル実行がコンテキストの完全な分離を意味するわけではなく、チーム協調時には共有チャンネル内の出力とコンテキストが境界を越えて同期される点に注意が必要です。
