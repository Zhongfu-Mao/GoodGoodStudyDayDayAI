# 週次サマリー

- **Harness Engineering が今週の最大主線** になった。
- **Claude Opus 4.7** は、coding・vision・推論粒度をまとめて更新する旗艦モデルの新しい型を見せた。
- **プラットフォーム入口の競争** が Codex、Windsurf、Perplexity、OpenClaw の各陣営で激しくなっている。

## 今週の四つの要点

## 1. Coding workflow が Agent によって再設計されている

- RIP Pull Requests、Windsurf 2.0、Claude Code、Codex の一連の動きは、補完ではなく workflow そのものの再設計を示している。

## 2. モデル製品ラインが多層化した

- Opus 4.7 が旗艦、GPT-Rosalind が垂直特化、Mythos が gate 付き前線版という構図で整理できる。

## 3. 推論コスト最適化が競争力そのものになった

- 量子化、KV cache、speculative decoding、バッチング設計の差が、モデル差より実務で効く局面が増えている。

## 4. 合規とプラットフォーム境界が開発者体験を変え始めた

- Anthropic KYC は利用条件そのものを変え、OpenClaw 論争はアーキテクチャ選択の重要性を浮き彫りにした。

## 継続観察ポイント

- 多 Agent IDE が本当に PR 中心フローを変えるか。
- KYC と地域制限がモデル選定をどう変えるか。
- Perplexity、Codex、OpenClaw のうち誰が「個人 AI OS」入口を取るか。
