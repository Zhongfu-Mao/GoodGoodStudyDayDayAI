# 週次サマリー

- 今週もっとも明確だった主線は、**Agent が prompt engineering から harness engineering へ移ったこと**。
- オープンモデル競争は、性能だけでなくライセンス、文脈長、多モーダル性、coding 能力まで含むようになった。
- ツール層では OCR、本地実行、事後学習フレームワーク、評価手法が大きく前進した。

## 今週の四つの要点

## 1. Agent システムは「実行環境の設計」が勝負になった

- Agent Harness、Advisor Strategy、Build Agents That Don’t Fail in Production が示したのは、文脈、記憶、権限、回復、検証をどう設計するかが中心課題になったということ。

## 2. Claude Mythos / Glasswing が gate 付き先端モデルの物語を開いた

- 最強能力を一般公開せず、限定協力先にだけ解放する形は、今後の先端モデル戦略のひな型になり得る。

## 3. オープンモデルとオープンツールが同時に成熟している

- Gemma 4、Qwen 3.6-Plus、GLM-5.1 がモデル側を押し上げ、TRL v1.0、Transformers v5、llama.cpp OCR が実装側を押し上げた。

## 4. 入口争いが始まった

- Perplexity は金融 Agent へ、Claude は Office 入口へ、Hermes / OpenClaw は個人 harness へと広がっている。

## 継続観察ポイント

- Harness Engineering が業界共通語になるか。
- gate 付き先端モデルが標準化するか。
- OCR と本地マルチモーダルが最初の大規模導入波になるか。
