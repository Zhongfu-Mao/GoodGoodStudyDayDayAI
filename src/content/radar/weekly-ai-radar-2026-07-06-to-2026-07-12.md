# 本周范围

- 时间窗口：2026-07-06 ~ 2026-07-12
- 覆盖日报：2026-07-06 至 2026-07-12

# 趋势卡片

- Agent 工程的主线从“会用工具”转向“能长期运行”。Plano、Modal、Google Agents CLI、SPEC.md、Agent Governance Toolkit、BrowserOS、Desktop Commander MCP 和 OpenViking 都在强调状态、权限、评估、恢复、浏览器/终端接口和可复查交付。
- 模型竞争正在被产品架构重写。GPT-5.6 的模型阶梯、GPT-Live 的实时语音、Grok 4.5 的 coding-agent 场景、DSpark 的 speculative decoding 和 Muse Spark / Qwen / vLLM 的效率信号，说明模型选择已经进入成本、延迟、吞吐、默认值和任务路由层。
- 评测本身成为工程对象。SWE-Bench Pro 复核、Fable 5 安全分类器、Agent Governance Toolkit、Bio Bounty、国家安全原则和 CJS jailbreak severity 都显示，高价值 agent 工作流必须把风险分级、任务定义、证据记录和复核流程放进系统设计。
- 工具生态围绕本地可操作对象重组。Firecrawl、Rowboat、BrowserOS、Desktop Commander MCP、OfficeCLI、claude-video、open-notebook、speech-to-speech 和 NotebookLM Short Video Overviews 把网页、文件、浏览器、语音、视频、知识库和 notebook 变成 agent 可以操作的对象。
- 行业信号从模型发布扩展到基础设施与组织边界。Palantir 与 token-based AI 平台的冲突、Meta 算力资产化、OpenAI / Microsoft 365、澳大利亚支付系统、Deutsche Telekom 和大疆救援，说明 AI 正在进入预算、供应链、公共安全和企业运营模型。

## Agent 工程与治理控制面

### Agent 数据平面、云基础设施和生产链路开始合并

- **发布日期**：2026-07-06 至 2026-07-10
- **主题**：Agent data plane、cloud runtime、deployment lifecycle
- **链接**：[katanemo/plano](https://github.com/katanemo/plano)
- **摘要**：Plano 把 orchestration、routing、guardrail 和 trace 放进 agentic app 的数据平面；Modal 把云基础设施从 developer experience 推向 agent experience；Google Agents CLI 把 ADK agent 的搭建、评估和部署合成生产链路；Daily Dose 的 RL environment 则提醒团队，模型训练和 agent 评估需要可复现实验环境。共同信号是，agent 不再是 IDE 旁边的脚本，而是要接入运行时、评估、部署和云资源的系统。

### SPEC.md、治理工具和 parallel-agent harness 把“停止条件”显性化

- **发布日期**：2026-07-11 至 2026-07-12
- **主题**：Spec-driven coding、governance、parallel agents
- **链接**：[DeepLearning.AI The Batch](https://www.deeplearning.ai/the-batch/issue-361)
- **摘要**：DeepLearning.AI 强调用 SPEC.md、测试计划和人工反馈驱动 agentic coding loop；Latent.Space 把 parallel-agent 能力与 harness 产品地位联系起来；Microsoft Agent Governance Toolkit 则把治理从提示词安全推进到确定性控制面。高质量 agent workflow 的核心不只是“多跑几个 subagent”，而是清楚定义任务、权限、停止条件、证据链、复核路径和失败处理。

### 实时语音、浏览器和终端接口成为 agent 的标准操作层

- **发布日期**：2026-07-06 至 2026-07-12
- **主题**：Realtime voice、browser interface、terminal control
- **链接**：[BrowserOS](https://github.com/browseros-ai/BrowserOS)
- **摘要**：ByteByteGo 的 OpenAI 低延迟语音架构、GPT-Live、Hugging Face speech-to-speech、BrowserOS、Desktop Commander MCP 和 Cursor mobile remote control 显示，agent 的操作面正在覆盖实时语音、浏览器、本地文件、终端、移动监督和可替换语音 pipeline。真正的工程挑战是把这些接口放进权限、状态、日志、回退和人工接管机制里。

## 模型、评测与效率竞争

### GPT-5.6、Grok 4.5 和 GPT-Live 把模型发布推向产品架构问题

- **发布日期**：2026-07-09 至 2026-07-12
- **主题**：Frontier models、realtime interaction、product architecture
- **链接**：[OpenAI GPT-5.6](https://openai.com/index/gpt-5-6)
- **摘要**：OpenAI 发布 GPT-5.6 与 ChatGPT Work，把模型、桌面、连接器、自动化任务和企业治理放到同一个工作流；GPT-Live 用 full-duplex 语音模型拆分实时对话和深度推理；Grok 4.5 则以 coding-agent 场景和性价比切入前沿模型竞争。模型发布不再只是能力展示，而是默认模型、协作界面、成本层级、企业连接器和任务编排的产品架构问题。

### 推理效率、服务吞吐和低成本模型成为模型侧第二战场

- **发布日期**：2026-07-11 至 2026-07-12
- **主题**：Inference efficiency、speculative decoding、cost curve
- **链接**：[DeepSeek DSpark](https://arxiv.org/abs/2607.05147)
- **摘要**：DeepSeek DSpark 用 confidence-scheduled speculative decoding 提升服务吞吐，V4-Pro-DSpark 把 speculative module 作为可部署附件放到 Hugging Face；Artificial Analysis 的 Muse Spark 1.1、Qwen3.6 量化、vLLM speculative decoding 和 Gemma 加速挑战共同说明，模型竞争正在进入“足够好、足够快、足够便宜”的服务曲线。企业选型必须看真实吞吐、延迟、缓存、量化和部署复杂度。

### 安全评测、代码评测和生物风险把“能力”拆成风险分级

- **发布日期**：2026-07-07 至 2026-07-12
- **主题**：Evaluation quality、model safety、risk taxonomy
- **链接**：[Anthropic Fable safeguards](https://www.anthropic.com/news/fable-safeguards-jailbreak-framework)
- **摘要**：Fable 5 网络安全分类器和 CJS jailbreak severity 框架把双用途能力拆成风险等级；OpenAI 对 SWE-Bench Pro 的复核显示评测任务本身也可能有缺陷；Bio Bounty 和国家安全原则把高风险用途纳入持续测试和问责。模型能力越强，团队越需要把评测集、任务范围、误用路径和复核机制变成可维护资产。

## 工具、知识资产与 GitHub 趋势

### RAG、长期记忆和本地 second brain 继续走向系统化

- **发布日期**：2026-07-09 至 2026-07-12
- **主题**：RAG、memory、context database
- **链接**：[OpenViking](https://github.com/volcengine/OpenViking)
- **摘要**：Daily Dose 把 RAG 和 fine-tuning 分成运行时知识与默认行为两层，Rowboat 把本地 second brain 做成常驻 agent 和知识图谱，OpenViking 试图统一 agent memory、RAG 和 skills，TencentDB-Agent-Memory 强调本地化和分层写入。知识系统正在从“检索一个片段”转向“维护长期上下文、技能、图谱和可更新行为”的基础层。

### Skills、Office、视频和 notebook 工具把工作对象变成 agent 可调用流程

- **发布日期**：2026-07-07 至 2026-07-12
- **主题**：Skills、document workflow、video / notebook assets
- **链接**：[Google Stitch Skills](https://github.com/google-labs-code/stitch-skills)
- **摘要**：addyosmani/agent-skills、taste-skill、mattpocock/skills、Stitch Skills、OfficeCLI、claude-video、NotebookLM Short Video Overviews、open-notebook 和 open-notebook 的 podcast 自动化都指向同一趋势：工作对象正在被打包成 agent 可复用流程。文档、设计、视频、notebook、语音和网页不再只是输入输出，而是可被技能化、版本化和自动化的资产。

### GitHub 趋势显示安全、防护和本地控制成为 coding agent 的基础设施

- **发布日期**：2026-07-06 至 2026-07-12
- **主题**：Security agents、local control、agent workbench
- **链接**：[usestrix/strix](https://github.com/usestrix/strix)
- **摘要**：Strix 把安全测试 agent 从扫描器推进到可验证 PoC 和 CI 阻断；gastown 用 git-backed hooks 和持久 ledger 管理多 agent 长任务；Desktop Commander MCP、BrowserOS、orca、pentagi 和 AI job search repo 显示，本地控制、并行 worktree、渗透测试、移动跟进和工作流自动化正在成为 coding agent 基础设施。
