# 本周范围

- 时间窗口：2026-06-22 ~ 2026-06-28
- 覆盖日报：2026-06-22 至 2026-06-28

# 趋势卡片

- Agent engineering 的重心从“模型会不会调用工具”转向 loop、harness、memory、permissions、evaluation、cost、review 和 deployable workflow。
- 模型竞争继续细分：长上下文、computer use、post-training RL、MTP retrofit、开源 MoE、评测污染和前沿模型访问门控都进入工程决策。
- 企业 adoption 不再只是 ChatGPT seat。OpenAI / Samsung、Omio、Coinbase、Baseten、Anthropic 研究都显示，AI 会进入预算、权限、支付、员工职责和组织流程。
- GitHub 趋势从单个工具扩展到 agent-readable specs、代码图谱、记忆层、video / SEO / 文档处理等可被 agent 调用的业务系统。
- 下周需要继续看三个问题：长程 agent 的评测是否足够抗作弊，代码库/记忆图谱是否真的减少 token 浪费，以及模型访问门控会怎样影响小团队和独立开发者。

## Agent engineering 与可运行系统

### Loop、harness 与可验证完成条件成为 agent 工程底座

- **发布日期**：2026-06-22 至 2026-06-24
- **主题**：Agent loop、harness、verification
- **链接**：[Daily Dose](https://blog.dailydoseofds.com/)
- **摘要**：6 月 22 日到 24 日的信号把 agent 工程推向系统化：DeerFlow、ruflo、Hermes Agent、ByteByteGo 的 agentic engineering setup、Daily Dose 的 loop engineering、Vercel Eve、MDN MCP server 和 CopilotKit 都在说明同一个事实。agent 可靠性不来自更长 prompt，而来自明确的 context boundary、tool-facing docs、外部验证、团队协作界面、可回滚 spec 和持续运行时。agent 的“完成”也不能只靠自我声明，而要有外部检查、test、review 和 stop condition。

### 长程评测、权限和安全把 agent 从 demo 推向治理对象

- **发布日期**：2026-06-23 至 2026-06-28
- **主题**：Security、evaluation、permission boundary
- **链接**：[OpenAI Daybreak](https://openai.com/index/daybreak/)
- **摘要**：OpenAI Daybreak、Patch the Planet、Gray Swan、Strix、AgentCard、METR、OSWorld 2.0、MirrorCode、local coding agent 权限清单等信号共同说明，agent 的风险已经从 prompt 层进入真实系统层。它们需要浏览器、文件、shell、支付、身份、漏洞修复和长时间任务环境，因此必须被评测、限制、记录和复核。高质量 agent workflow 会越来越像工程控制系统：先定义输入面和权限，再执行，再自评估或第三方评估，最后留下可追溯产物。

### 代码知识图谱、记忆层和需求协议正在减少 agent 的盲目读文件

- **发布日期**：2026-06-28
- **主题**：Codebase graph、memory、spec protocol
- **链接**：[Fission-AI OpenSpec](https://github.com/Fission-AI/OpenSpec)
- **摘要**：OpenSpec、CodeGraph、TencentDB Agent Memory、graphify、open-seo 等项目把 agent workflow 的瓶颈指向 context management。OpenSpec 用 change folders 和 task lists 管需求协商；CodeGraph 与 graphify 预先把代码和资料做成可查询图谱；TencentDB Agent Memory 用 layered memory 和 Mermaid task canvas 压缩长任务历史；open-seo 则把垂直业务流程开放给 agent 调用。agent 的工程效率正在从“读更多文件”变成“读结构化 context”。

## 模型、评测与基础设施

### 开源模型、长上下文与 post-training 继续进入细分竞争

- **发布日期**：2026-06-24 至 2026-06-26
- **主题**：Open models、long context、post-training
- **链接**：[Latent.Space / AINews](https://www.latent.space/)
- **摘要**：GLM-5.2、Ornith、Liquid LFM2.5、slime、OpenPipe ART、ByteByteGo 对 LLM / SLM 的组合分析，以及 The Batch 对更现实 agentic benchmarks 的讨论，显示模型竞争已不再只看 leaderboard。长上下文、agentic coding、post-training RL、reward design、deployment cost、SLM + LLM routing 和评测污染，都在影响模型是否能进入真实工作流。对于工程团队，模型选择正在变成“任务、成本、评测、服务路径”的组合问题。

### 前沿模型访问、评测污染和 release gating 改变研发供应链

- **发布日期**：2026-06-26 至 2026-06-28
- **主题**：Model access、safety gating、evaluation realism
- **链接**：[OpenAI GPT-5.6 preview](https://openai.com/index/previewing-gpt-5-6-sol/)
- **摘要**：OpenAI GPT-5.6 Sol / Terra / Luna、可信伙伴预览、高风险实时分类器、Cursor 的 benchmark 污染讨论、OSWorld 2.0 与 METR 长程评测，让模型发布从“能力公告”变成供应链事件。前沿模型能力越强，访问门槛、评测环境、红队记录、成本档位和降级路径就越重要。小团队不能只依赖某个模型的峰值能力，还需要记录替代模型、失败模式和可复现评测。

### 推理效率从“更便宜模型”转向 cache、speculation、routing 与 serving path

- **发布日期**：2026-06-24 至 2026-06-28
- **主题**：Inference efficiency、cost governance
- **链接**：[Google Research](https://x.com/GoogleResearch/status/2070579898465567159)
- **摘要**：Google Research 的 Multi-Token Prediction retrofit、Daily Dose 的 DFlash speculative decoding、Coinbase / Baseten 的 cost governance、Recursive Language Models 和 Corrective RAG 都说明，推理效率正在进入系统设计层。企业不是简单少调用模型，而是通过 routing、cache hit、speculative decoding、RAG correction、context policy 和 task tiering 来控制成本。模型 serving path 本身正在成为模型能力的一部分。

## 组织采用、行业与商业化

### Enterprise AI 从 seat adoption 进入工作流重构

- **发布日期**：2026-06-22 至 2026-06-28
- **主题**：Enterprise adoption、workflow redesign
- **链接**：[OpenAI / Samsung](https://openai.com/index/samsung-chatgpt-enterprise/)
- **摘要**：OpenAI / Samsung、Omio conversational travel、Every 的 token budget、Coinbase / Baseten 成本治理、Anthropic 工作影响研究和 Hugging Face ARR 过亿美元，都把 enterprise AI 推出单一聊天入口。企业正在把 AI 接进员工工作流、交易库存、预算控制、客服、采购、研发和合规流程。采用难点也随之变化：不再只是给员工账号，而是为 AI 设置权限、预算、指标、审计路径和职责边界。

### AI 产业竞争同时发生在人才、算力、资本和组织结构

- **发布日期**：2026-06-22 至 2026-06-26
- **主题**：Talent、compute、capital、organization
- **链接**：[老范讲故事](https://lukefan.com/)
- **摘要**：老范讲故事本周关于 DeepMind 人才流动、Anthropic / 阿里蒸馏争议、Sakana Fugu 编排能力、DeepSeek 和中国 AI 结构的分析，与 AINews 的 SpaceX / xAI neocloud、OpenAI 自研芯片和 Hugging Face 商业化信号放在一起看，说明 AI 竞争已经是组织、人才、资本、算力和产品路线的综合竞争。模型能力只是表层结果，长期优势取决于人才流动、算力效率、商业分发和组织执行。

- **发布日期**：2026-06-23 至 2026-06-28
- **主题**：Agent developer tools

- **摘要**：MDN MCP server、Vercel Eve、Claude Code plugin marketplace、Anthropic Cybersecurity Skills、gstack、mattpocock/skills、OpenSpec 等项目，把 agent 可读规范、技能包、插件市场、浏览器 QA 和发布动作做成开发者基础设施。开发者生态正在把“如何要求 agent 工作”从口头 prompt 变成安装包、目录结构、规范文件和可复核流程。

- **发布日期**：2026-06-23 至 2026-06-28
- **主题**：Vertical agent tools
- **链接**：[every-app/open-seo](https://github.com/every-app/open-seo)
