# 今週の範囲

- 対象期間：2026-08-03 ~ 2026-08-09
- 対象日報：2026-08-03〜2026-08-09

# トレンドカード

- Agentの成績は「model × harness」で決まる。同じmodelでもcoding harnessを替えるとSWE-bench Pro pass@1が倍増し、default model、routing、context、cacheもタスク単価を一桁変え得る。
- 永続stateが新しいsystem boundaryになった。Deep Agents、Cloudflare Computer、LoopX、ChatGPT Work、cross-session messageはcheckpoint、復旧、権限、予算、因果traceをruntimeの中心へ移した。
- Open modelの能力幅が広がった。Kimi K3、DeepSeek-V4-Flash、MiniMax H3、FLUX 3 Video、device翻訳がlong-horizon agent、multimodal生成、video/audio、local inferenceを覆う。
- Securityはcontent filteringから現実の副作用へ広がった。AISI incident、Uber ADR、Aegis-AI、SecureForge、生物安全classifierはnetwork、tool、data、approval、回帰証拠の分離を求める。
- AI利用はworkflow再設計へ進む。product manager、finance、legal、map action、Word tracked changes、enterprise ingestionは、制約設計、専門判断、最終責任の価値を高める。

## Harness、state、本番control plane

### Harnessはmodelの外装ではなく、成功率とcostを決める共同変数

- **公開期間**：2026-08-03〜2026-08-09
- **テーマ**：coding agent、context、cache、routing、unit economics
- **リンク**：https://www.latent.space/p/ainews-zawinskis-law-of-multiagents
- **要約**：同一taskでharnessだけを替えると、SWE-bench Proの成績は23%から52%まで変動し、model間のharness順位もほぼ相関しなかった。Databricksのcost管理、Megakernel、RAG prefill latency、SIE shared GPUも、成功率・遅延・価格がmodel、context、cache、scheduler、hardwareの協調で決まることを示す。評価単位は「model+harness+budget」であるべきだ。

### Persistent thread、checkpoint、durable stateが復旧を製品機能にする

- **公開期間**：2026-08-05〜2026-08-09
- **テーマ**：persistent runtime、checkpoint、approval、shared state
- **リンク**：https://www.langchain.com/blog/interrupt-2026-overview
- **要約**：Managed Deep Agentsはpersistent thread、streaming、checkpoint、human approvalを提供し、Cloudflare ComputerはDurable Objectを権威stateにする。LoopXはdurable goal、gate、evidence、quotaで長期taskを制御し、cross-session messageは協働面を広げた。復旧性が高いほどhidden stateと循環依存も増えるため、因果log、idempotent tool、budget cap、高risk approvalを同時に設計する必要がある。

### Connectorが呼べてもdata完全性は保証されず、runtime evidenceがacceptance条件になる

- **公開期間**：2026-08-04〜2026-08-07
- **テーマ**：MCP、pagination、observability、runtime verification
- **リンク**：https://github.com/mattpocock/skills
- **要約**：MCP実測ではpaginationとsemantic constraintが問題になった。code-review-graph、agent-device、Hark Handoff、DoorDash Agent Gateway、T3 Codeはcode graph、実browser、identity、credential、subagent観測で現場を補う。結果件数、pagination、権限、環境version、execution log、最終UI状態までacceptance criteriaに含めたい。

## Model、推論効率、multimodal

### Open modelは「download可能」からlong-horizon agentとunit cost競争へ

- **公開期間**：2026-08-03〜2026-08-09
- **テーマ**：Kimi K3、DeepSeek-V4-Flash、distillation、AirLLM
- **リンク**：https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731
- **要約**：Kimi K3はsparse activation、native multimodal、training-time quantizationで長期agentを狙い、DeepSeek-V4-Flashは13B active parameterと1M contextで低cost推論を進めた。MiniMaxのLoRA distillationとAirLLM layer streamingもsample数とVRAMを圧縮する。open weightの事業価値はlicenseからsovereign deployment、運用、integration、upgradeへ移り、再現条件と保守costも比較対象になる。

### Video、audio、device modelが新しいmultimodal delivery stackを作る

- **公開期間**：2026-08-05〜2026-08-08
- **テーマ**：MiniMax H3、FLUX 3 Video、Gemma Translator、voice agents
- **リンク**：https://github.com/nicholasgasior/gemma-translator
- **要約**：MiniMax H3とFLUX 3 Videoはvideo、native audio、multi-shot生成を公開serviceへ進め、Gemma TranslatorはRaspberry PiでASR、translation、TTSをoffline連結する。LiveKit AgentsとChatGPT Voice Modeはreal-time voice orchestrationを示すが、latency、turn detection、narration誤認がtask完了を左右する。品質、同期、device resource、privacy、復旧を個別に検証すべきだ。

### Scienceと専門領域はgeneral Q&Aでなく実行taskでagentを測り始める

- **公開期間**：2026-08-03〜2026-08-08
- **テーマ**：ExploitGym、phage design、enterprise data、domain evaluation
- **リンク**：https://github.com/ethz-spylab/exploitgym
- **要約**：ExploitGymは898件の実脆弱性で実行可能exploitを要求し、AI phage研究はcandidate genomeから実験上の複製結果へ進んだ。IBM Bobはlegacy data ingestion、test、MCP生成をenterprise workflowへ接続する。いずれもtask-level rubric、隔離環境、domain expert、現実結果の検証を必要とし、model self-evaluationや一回の回答では足りない。

## Security、governance、現実の副作用

### Agent riskの中心は「誤発言」から「現実環境で誤動作」へ

- **公開期間**：2026-08-04〜2026-08-08
- **テーマ**：network isolation、tool permission、prompt injection、side effects
- **リンク**：https://www.aisi.gov.uk/blog/agentic-ai-security-incidents
- **要約**：英国AISIの越権incident、LLM threat map、Uber ADRは、instructionとdataの混在、open network、広いtool権限、防護無効化がmodel errorを現実の副作用へ変えると示した。SecureForge、Aegis-AI、Anthropicのbio classifierは自動改善と段階防護を示すが、安全判断にはisolated test、real regression set、external review、中断可能なexecutionが必要だ。

### Hardware、人材、規制がAI競争をsupply chainとevidence preservationへ拡張

- **公開期間**：2026-08-03〜2026-08-08
- **テーマ**：compute supply、chips、trade secrets、government testing
- **リンク**：https://www.amd.com/en/newsroom/press-releases/2026-8-3-amd-and-anthropic-announce-strategic-partnership.html
- **要約**：AMDとAnthropicは2GW chip、model採用、equity arrangementを結び、AMDのTaalas買収はmodel-specific hardwareを強化した。Appleのtrade secret紛争と米国のfrontier model test案は、人材移動、release前access、evidence preservationを競争条件にする。model roadmapはenergy、package、contract、regulation、供給継続性から切り離せない。

- **リンク**：https://github.com/google/skills

### Document、PDF、Office workflowは追跡可能な成果物を重視

- **リンク**：https://github.com/anyproto/anydoc
- **要約**：pdf-inspectorはOCR要否を判定してcostをrouteし、anydocは統一Rust modelでOffice、EPUB、CSV、PDFを扱う。Claude for Microsoft 365は契約提案をWord tracked changesに落とす。共通点はpage、structure、change history、人間のaccept境界を保持し、AI出力を既存review systemへ入れることだ。
