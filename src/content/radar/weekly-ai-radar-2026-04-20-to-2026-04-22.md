# 本周范围

- 时间窗口：2026-04-20 至 2026-04-22
- 这一篇更像一份“短周报”，覆盖的是最近三天里最密集的一组 Agent runtime、模型和平台信号。


# 本周结论

- **Agent runtime 的行业共识正在成型**：zero-secret、结构化审查、失败重规划、按需上下文加载，已经不再是零散技巧，而是一组逐渐稳定的工程原则。
- **Context Engineering 正在从 prompt 技巧变成系统设计问题**：backend 如何暴露 schema、状态和错误，比单纯换一个更强模型更影响 token 成本与成功率。
- **前沿模型的竞争重心已经外溢**：多 Agent 持续运行、设计工具生成、机器人 VLA、diffusion LLM、检索底座等能力一起上桌，产品边界明显拉宽。

## 本周四条主线

## 1. Zero-secret runtime 正从理念变成标准设计

- GitHub Agentic Workflow 最值得记的不是“又一个 AI 功能”，而是它明确把 Agent 放进受限容器、把 Secret 放在代理层、把写操作放进确定性审查管线。
- 这和 OpenAI Codex 团队独立收敛出的“Agent 不应直接接触 Secret”形成强呼应，说明运行时安全已经开始有行业级共识。

## 2. Context Engineering 进入后端与工具链层

- `04-21` 最重要的工程信号是：Agent 的 token 成本和错误回合，很多时候不是模型不够强，而是后端返回的信息太散、太重、太不结构化。
- Skills、CLI、MCP 的三层分工，正在成为一种很实用的实现模板：静态知识按需加载、执行结果用结构化 JSON 回传、状态检查交给轻量 MCP。

## 3. Frontier model 的竞争从“更强”转向“更能干活”

- Kimi K2.6 把 300 个并行子 Agent、12+ 小时持续运行这类系统能力推到台前。
- Claude Design、ambient memory、Monologue Notes 这类产品则把模型能力从聊天窗口向 design、meeting、长期上下文管理外溢。
- Diffusion LLM、DenseOn/LateOn、GR00T N1.7 说明底层技术栈本身也在快速替换与扩展。

## 4. 资本、平台与供应链信号开始和技术主线缠在一起

- DeepMind 与 Anthropic 的算力军备竞赛持续升温。
- DeepSeek 的融资与治理问题、北京人形机器人半马、SpaceX IPO 争议，都在说明“AI 技术趋势”已经很难和产业组织方式完全分开看。

## 本周值得继续跟踪

- zero-secret runtime 会不会在更多 IDE / agent 平台中变成标配。
- Context Engineering 会不会从少数工程文章里的术语，变成团队普遍采用的后端设计语言。
- Kimi、Claude、Codex、Hermes 这些产品最后会不会收敛成几种稳定的 Agent 入口形态。
