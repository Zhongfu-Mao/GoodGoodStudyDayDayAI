# 本周范围

- 时间窗口：2026-04-14 ~ 2026-04-19
- 覆盖日报：2026-04-14、2026-04-15、2026-04-16、2026-04-17、2026-04-18、2026-04-19


# 本周结论

- Harness Engineering 在这一周彻底坐实为主线，而且开始从工程文章外溢到 IDE、PR、memory、平台边界和工作区设计。
- Claude Opus 4.7、Mythos、GPT-Rosalind 这些信号放在一起看，模型产品线已经进入“旗舰快迭代 + 门控前沿版 + 垂直专用版”的分层阶段。
- 平台入口争夺显著升温，Codex、Windsurf、Perplexity、OpenClaw 已经不只是做工具，而是在争夺下一层 AI 操作系统入口。

*代表图来自 [Anthropic Claude Opus 4.7](https://www.latent.space/p/ainews-anthropic-claude-opus-47-literally)。这一周后半段最集中的变化，就是旗舰模型快迭代、Agent 工作流被重写、产品入口竞争同时加速。*

## 1. Harness Engineering 从“概念”变成“通用语”

- **[Evolution of Agent Landscape From 2022-26](https://blog.dailydoseofds.com/p/evolution-of-agent-landscape-from)** 直接把这条演化线说透了：weights → context → harness engineering。
- **[Build Agents That Never Forget](https://blog.dailydoseofds.com/p/build-agents-that-never-forget-98a)**、**[Google solved an Old RNN Problem](https://blog.dailydoseofds.com/p/google-solved-an-old-rnn-problem)**、**Notion's Token Town** 这些文章补上的，是记忆、上下文管理和软件工厂层的细节。
- 到这一周，大家讨论的已经不是“Agent 会不会调用工具”，而是 runtime、memory、workspace、approval、recovery 和 observability 怎么一起工作。

## 2. Coding workflow 正在被 Agent 系统性重写

- **[AINews RIP Pull Requests (2005-2026)](https://www.latent.space/p/ainews-rip-pull-requests-2005-2026)**、**[Windsurf 2.0 — Agent Command Center](https://windsurf.com)**、**[10 Must-use Slash Commands in Claude Code](https://blog.dailydoseofds.com/p/10-must-use-slash-commands-in-claude)**、**[OpenAI Codex 超级 App 化](https://www.therundown.ai/p/openai-superapp-hiding-inside-codex)** 共同指向一个事实：AI coding 已经不只是在补全代码，而是在接管流程。
- PR、review、CI、approval、workspace、parallel agent 协作，这些本来属于工程管理的问题，现在逐步进入产品设计层。
- 如果说上一周是在定义 Agent 组件，这一周更像是在重写“团队怎样开发软件”。

## 3. 模型侧进入“旗舰 + 前沿门控 + 垂直专用”三层结构

- **[Anthropic Claude Opus 4.7](https://www.latent.space/p/ainews-anthropic-claude-opus-47-literally)** 代表旗舰模型仍在高频迭代，而且不只是 coding 提升，视觉理解和推理粒度也一起提升。
- **Mythos** 仍代表门控前沿模型的存在形态，说明实验室会继续把最强能力留在更窄的发布渠道里。
- **[OpenAI GPT-Rosalind — 首个生命科学专用模型](https://www.therundown.ai/p/openai-superapp-hiding-inside-codex)** 则是第三层：高价值领域专用模型开始真正进入现实业务场景。
- 这三条线放在一起，比单纯看一张 benchmark 表更能解释接下来模型市场的产品形态。

## 4. 推理效率、服务拓扑和成本控制重新变成核心竞争力

- **[72 Techniques to Optimize LLMs in Production](https://blog.dailydoseofds.com/p/72-techniques-to-optimize-llms-in)** 是这一周最重要的工程底稿之一，因为越来越多团队会发现，真实差距来自吞吐、延迟、成本和稳定性，而不只是模型能力。
- **Memory Caching**、**Top Local Models List**、**本地模型部署路线** 和 **多层服务架构设计** 这些内容都在说明：生产竞争力越来越取决于系统设计，而不是单一模型分数。
- 这也解释了为什么 ByteByteGo 的 JVM、数据库设计、服务架构文章在这一周并不显得“离题”，因为它们实际上都在回答同一个问题：AI 系统到底要怎么运行。

## 5. 合规、平台边界和商业模式开始反向塑造产品

- **[Claude KYC 上线：中国开发者影响解析](https://lukefan.com/2026/04/17/anthropic-claude-selective-kyc-china-user-crackdown/)** 说明使用资格本身正在变成产品体验的一部分。
- **[微软龙虾要来了？CEO 亲自下场，为什么我却不看好？](https://lukefan.com/2026/04/16/microsoft-openclaw-ai-agent-cloud-client-tradeoffs/)** 则提醒我们，平台架构和商业模式之间的冲突会直接影响 Agent 产品设计。
- **Perplexity Personal Computer**、**Claude Design**、**Allbirds ditches sneakers for AI compute** 这些信号则说明，入口、设计工作流和资本市场叙事也都在跟着变化。

## 本周值得继续跟踪

- 多 Agent IDE 和 agentic workflow 会不会真的压缩传统 PR 流程。
- KYC、支付和地域限制会不会进一步改变开发者默认使用的模型组合。
- Codex、Perplexity、OpenClaw、Claude Design 这几条产品线里，谁最有机会占住下一层 AI 操作系统入口。
