# 本周结论

- **Harness Engineering 坐实为本周最大主线**，并开始外溢到 IDE、PR、Agent 平台和工作区设计。
- **Claude Opus 4.7** 把“更强 coding + 更强视觉 + 更细推理档位”组合成了新一轮旗舰模型迭代范式。
- **平台化入口** 成为产品层关键词，Codex、Windsurf、Perplexity、OpenClaw 都在抢这个位置。

## 一周里发生了什么

## 1. Coding workflow 正在被 Agent 重写

- RIP Pull Requests、Windsurf 2.0、Claude Code 工作流、OpenAI Codex Superapp 化，这几条信号放在一起看，说明 AI coding 已经从“补全代码”走到“管理整个工作流”。
- 以后团队真正要设计的，不只是提示词，而是审批、验证、工作区和多 Agent 协作。

## 2. 模型侧进入“旗舰快迭代 + 垂直专用化”

- Opus 4.7 代表旗舰模型继续高频迭代。
- GPT-Rosalind 代表垂直专用模型开始进入高价值行业。
- Mythos 代表门控前沿模型仍然会作为实验室的战略资产存在。

## 3. 推理成本优化成为生产竞争力

- 72 Techniques to Optimize LLMs in Production 这类内容的重要性明显提升，因为模型能力差距正在逐渐让位于成本、吞吐和稳定性差距。
- Memory Caching、PagedAttention、Speculative Decoding 之类的方向会继续反复出现。

## 4. 合规与平台边界开始影响开发者生态

- Anthropic KYC 直接作用于使用门槛。
- OpenClaw 的争议则说明平台架构与商业利益正在反向塑造产品形态。

## 本周值得继续跟踪

- 多 Agent IDE 会不会真的压缩传统 PR 流程。
- KYC、支付与地区限制会不会进一步改变开发者常用模型组合。
- Perplexity、Codex、OpenClaw 谁最有机会占住“个人 AI 操作系统”入口。
