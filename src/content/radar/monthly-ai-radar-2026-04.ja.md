# 月次サマリー

4 月前半から中旬にかけて、AI 業界で最も明確だった変化は「さらに強いモデルが出た」ことよりも、三つの長期トレンドが同時にはっきりしたことだった。

1. **Agent の主戦場がランタイムに移った**  
   記憶、技能、プロトコル、承認、作業空間、回復能力、観測性がまとめて Harness Engineering 層を形作っている。

2. **モデル製品ラインが分層化した**  
   旗艦モデルの高速更新、gate 付き前線版、垂直特化モデルが同時に見えるようになった。

3. **入口そのものが再定義されている**  
   IDE、検索、ブラウザ、オフィス、本地アプリが AI によって作り替えられつつある。

![Agent Landscape の進化図](https://substack-post-media.s3.amazonaws.com/public/images/acc877e8-071d-4d5c-bcc5-c8dbe50e37c1_2114x1154.png)

*代表画像は [Evolution of Agent Landscape From 2022-26](https://blog.dailydoseofds.com/p/evolution-of-agent-landscape-from) のビジュアルから選定。月報の代表図としてこれが最も合っていて、4 月前半の最重要な長期変化が Agent 能力の runtime 層への外在化だったことを示している。*

## 今月の四つの主線

## 1. Harness Engineering が 2026 年の中心語になった

- Agent Harness、Advisor Strategy、Build Agents That Don’t Fail in Production、RIP Pull Requests を並べてみると、勝負はモデル単体ではなく実行環境設計にあると分かる。

## 2. オープンモデルは「完全な能力セット」を競い始めた

- Gemma 4、Qwen 3.6-Plus、GLM-5.1、Nucleus-Image は、性能だけでなく多モーダル、長文脈、端末動作、ライセンスまで含めて競っている。

## 3. ツール層では OCR、RAG、coding workflow が先に成熟している

- llama.cpp OCR、論文 OCR、Tabular Review、TRL v1.0、Claude Code などは、実務に近い層から浸透している。

## 4. プラットフォーム、合規、商業モデルが同時に締まってきた

- Codex、Windsurf、Perplexity、OpenClaw が入口を争い、Anthropic KYC が利用条件を変え始めた。

## 来月に向けた観察ポイント

- Harness Engineering が本当に共通語になるか。
- 多 Agent IDE がチーム協業をどこまで変えるか。
- 垂直特化モデルが生命科学、金融、セキュリティでどこまで広がるか。
