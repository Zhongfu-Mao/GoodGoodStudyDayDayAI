# 本周范围

- 时间窗口：2026-07-13 ~ 2026-07-19
- 覆盖日报：2026-07-13 至 2026-07-19

# 趋势卡片

- Agent 工程从“能调用工具”继续走向“能长期运行”。LLM routing、prompt caching、agentic RL、verifier runtime、SPEC.md、agent loop、sandbox、MCP、skills、浏览器 / 终端 / 语音接口都在把 agent 变成可恢复、可审计、可计量的系统。
- 模型竞争进入“能力 + 控制 + 成本”三轴。Kimi K3 与 Inkling 推高开放模型规模，GPT-Red 和 LLM-as-a-Verifier 把评测与安全变成训练组件，SparDA、reasoning effort、GPT-Live、Mercury 2 则把推理效率和实时交互拉到产品架构层。
- 企业 AI 的衡量口径从 token 单价转向 useful work per dollar。OpenAI Scorecard、Every 的 workflow 度量、Codex 使用增长、Cars24、客服 agent 和语音 lead intake 都显示，真正需要追踪的是成功任务、人工交接、运营修补和收入 / 成本结果。
- 工具生态正在把工作对象技能化。FineTune Studio、mcp-use、Hermes、Hallmark、Spec Kit、Graphify、Graphiti、wigolo、Open Interpreter、AIRI、PostHog 和 Copilot SDK 把代码、文档、训练、设计、记忆、搜索、观测和产品分析变成 agent 可调用流程。
- 行业边界从软件扩展到硬件、数据中心与制度。OpenAI / Apple 争议、Codex Micro、OpenAI 无屏硬件、Claude Code 地区争议、Grok Build 上传争议、纽约数据中心限制、frontier safety 联邦框架和 Hassabis 的预发布审查建议，都在重写平台责任边界。

## Agent 工程、harness 与运行系统

### Routing、cache、cloud 与 task cost 把 agent 成本治理推到架构层

- **发布日期**：2026-07-13 至 2026-07-14
- **主题**：LLM routing、prompt caching、AI cloud、cost per task
- **链接**：https://blog.dailydoseofds.com/p/how-llm-routing-actually-works-in
- **摘要**：Daily Dose 把 LLM routing 和 prompt caching 拆成生产架构问题：模型亲和性、session pinning、KV cache、静态前缀和路由策略共同决定真实成本。AINews 同时指出 agent 竞争正在从 token price 转向 cost per task。结合 Lightning AI cloud、Transformer Lab 和 Arch-Router，本周的成本主线很清楚：企业不能只比较模型单价，而要管理任务路由、缓存命中、训练评估环境和云资源状态。

### Agent loop、SPEC.md 与 verifier runtime 把停止条件和评测显性化

- **发布日期**：2026-07-14 至 2026-07-15
- **主题**：Agentic RL、agent loop、verifier harness、spec-driven development
- **链接**：https://blog.dailydoseofds.com/p/the-four-types-of-agent-loops
- **摘要**：Daily Dose 把 agent loop 分成 turn-based、goal-based、time-based 和 proactive 四类，Prime Intellect 的 verifiers 把 RL 环境拆成 taskset、harness 和 runtime，Spec Kit 与 SPEC.md 方向则把需求、测试和交付边界写成 agent 可执行项目流程。agent 工程的关键正在从“多跑几步”变成“什么时候继续、什么时候停止、如何评估、如何复核”。

### Sandbox、权限、记忆与接口层成为 coding agent 的底座

- **发布日期**：2026-07-16 至 2026-07-19
- **主题**：Local agent audit、sandbox、memory、web intelligence、runtime interfaces
- **链接**：https://github.com/KnockOutEZ/wigolo
- **摘要**：Grok Build 代码上传争议、Claude Code 地区争议、agent sandbox 讨论、Open Interpreter、AIRI、Graphiti 和 wigolo 指向同一件事：coding agent 不能只靠 prompt 约束。文件、网络、权限、记忆、搜索、缓存、执行日志和人工接管需要成为运行时的一部分。长期运行的 agent 会越来越像带审计和恢复能力的本地 / 云混合工作区。

## 模型、评测与实时交互

### 开放模型竞争进入万亿参数、多模态和长上下文区间

- **发布日期**：2026-07-15 至 2026-07-17
- **主题**：Open-weight models、long-context coding、multimodal MoE
- **链接**：https://www.kimi.com/blog/kimi-k3
- **摘要**：Kimi K3 把开放模型竞争推向 3T 级、百万 token 上下文和多模态长程 coding，Thinking Machines Inkling 则用 975B MoE 和原生多模态强化开放权重叙事。它们共同说明，开放模型的竞争不再只是 benchmark 分数，而是长上下文、工具调用、代码任务、推理成本和多模态输入如何组合成可部署能力。

### GPT-Red、Puppet 与 LLM-as-a-Verifier 把评测变成模型系统的一部分

- **发布日期**：2026-07-16 至 2026-07-18
- **主题**：Automated red teaming、user-belief evaluation、verifier models
- **链接**：https://openai.com/index/unlocking-self-improvement-gpt-red
- **摘要**：OpenAI 的 GPT-Red 用 self-play 强化学习扩展自动红队，Puppet benchmark 讨论模型影响用户信念的测量难题，LLM-as-a-Verifier 则把大模型用作通用验证器。评测正在从发布前 checklist 变成训练、部署和运行时控制的一部分，尤其适合高风险 agent、代码任务、医学和机器人场景。

### Reasoning effort、SparDA、GPT-Live 和 Mercury 2 改写推理控制面

- **发布日期**：2026-07-15 至 2026-07-19
- **主题**：Reasoning control、KV cache、realtime voice、diffusion reasoning
- **链接**：https://magazine.sebastianraschka.com/p/controlling-reasoning-effort-in-llms
- **摘要**：Ahead of AI 梳理 reasoning effort，SparDA 用 Forecast projection 预取长上下文 KV blocks，The Batch 的 GPT-Live 把实时语音和后台推理拆成双层系统，The Rundown 的 Mercury 2 则把 diffusion reasoning 推向实时语音 agent。模型侧的重点正在变成：什么时候多想、什么时候快速响应、如何压低缓存和上下文成本、如何支持持续交互。

### 代码知识图谱、语义元数据和观测底座成为 agent 开发基础设施

- **发布日期**：2026-07-14 至 2026-07-18

- **链接**：https://github.com/Graphify-Labs/graphify

### GitHub 趋势显示本地后端、命令防护与长期记忆需求上升

- **发布日期**：2026-07-13 至 2026-07-19
- **主题**：Backend resources、command guard、agent memory、local web intelligence
- **链接**：https://github.com/InsForge/InsForge
- **摘要**：InsForge、destructive_command_guard、notebooklm-py、Graphiti、wigolo、OpenPipe ART、AIRI、LingBot-Map 和 ai-engineering-from-scratch 显示，热门 repo 不只在追模型 demo，而是在补齐后端资源、命令执行安全、知识资产接口、长期记忆、网页智能、强化学习框架、数字伴侣和学习路径。趋势榜更像 agent 工程缺口清单。
