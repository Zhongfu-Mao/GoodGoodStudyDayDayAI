## 为什么 AI 需要向量

AI 模型无法直接理解原始的文字或图片。它需要一种通用的数学表示来处理各种类型的数据。向量（Vector）正是扮演了这一角色：将万物映射为数值数组。

- 一个词 → 300 维向量
- 一句话 → 768 维向量
- 一张图 → 2048 维向量

虽然维度越高通常意味着信息编码能力越强，但更关键的逻辑在于：**语义相近的实体，在向量空间中的位置也紧密相邻。**

## 向量空间的直觉理解

你可以将向量空间想象成一个高维的坐标系：

- 二维空间：每个点表示为 (x, y)。
- 三维空间：每个点表示为 (x, y, z)。
- AI 使用的 Embedding 空间：可能包含数百到数千个维度，但数学原理保持一致。

在这个空间中，具有相似含义的概念会被模型映射到相近的坐标点。例如，“猫”与“狗”之间的向量距离，通常会比“猫”与“飞机”之间的距离近得多。

## 内积与余弦相似度

在向量空间中，衡量两个向量相似性最常用的指标是余弦相似度（Cosine Similarity）：

$$
\cos(\theta) = \frac{a \cdot b}{\|a\| \|b\|}
$$

其中：
- $a \cdot b$ 是点积/内积（对应元素相乘后的累加和）。
- $\|a\|$ 和 $\|b\|$ 分别是向量的长度（模）。
- $\cos(\theta)$ 的取值范围在 -1 到 1 之间。

| 取值 | 业务含义 |
| --- | --- |
| 1 | 方向完全一致（语义极度相似） |
| 0 | 向量正交（彼此不相关） |
| -1 | 方向完全相反 |

余弦相似度的核心特征是：**只关注方向，不关注长度**。即使一个向量很短而另一个很长，只要它们指向同一个方向，相似度依然为 1。

## 为何首选余弦相似度而非欧氏距离

| 指标 | 核心关注点 | 典型适用场景 |
| --- | --- | --- |
| 余弦相似度 | 方向的一致性 | 文本相似度、语义搜索、推荐系统 |
| 欧氏距离 | 空间中的绝对距离 | 聚类分析、异常值检测 |
| 曼哈顿距离 | 各维度绝对差之和 | 高维稀疏数据、网格搜索 |

在高维空间中，欧氏距离的区分度会由于“维度灾难”而显著下降。余弦相似度由于对长度进行了归一化处理，在高维场景下的表现更为稳定和可靠。

## 实际应用场景

- **语义搜索**：将查询词与文档库全部向量化，通过余弦相似度检索最相关的结果。这是 RAG（检索增强生成）系统的核心环节。
- **推荐系统**：计算用户兴趣向量与商品向量的相似度，将最匹配的内容推送给用户。
- **内容去重**：当两篇文档的向量相似度超过预设阈值时，可判定为重复或高度相似内容。
- **自动化聚类**：在向量空间中利用 K-Means 等算法对相似数据进行自动分组。

## Python 代码示例

```python
import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

v1 = np.array([1, 2, 3])
v2 = np.array([2, 4, 6])  # 方向完全一致
v3 = np.array([3, -1, 0]) # 方向不相关

print(cosine_similarity(v1, v2))  # 输出: 1.0
print(cosine_similarity(v1, v3))  # 输出: ≈ 0.08
```
