## 为什么 AI 需要向量

AI 模型不能直接理解文字或图片。它需要一种数学表示来处理所有类型的数据。向量就是这种通用表示：把任何东西变成一组数字。

- 一个词 → 一个 300 维向量
- 一句话 → 一个 768 维向量
- 一张图 → 一个 2048 维向量

维度越高，能编码的信息越多。但关键不是维度数，而是**相似的东西在向量空间里距离近**。

## 向量空间的直觉

把向量空间想象成一个多维坐标系：

- 二维空间里，每个点是 (x, y)。
- 三维空间里，每个点是 (x, y, z)。
- AI 用的空间可能有几百到几千个维度，但原理相同。

在这个空间里，语义相近的概念会被映射到相近的位置。比如"猫"和"狗"的向量距离，会比"猫"和"飞机"的距离近。

## 内积与余弦相似度

判断两个向量有多相似，最常用的方法是余弦相似度：

$$
\cos(\theta) = \frac{a \cdot b}{\|a\| \|b\|}
$$

其中：
- $a \cdot b$ 是内积（对应元素相乘再求和）。
- $\|a\|$ 和 $\|b\|$ 是向量的长度（模）。
- $\cos(\theta)$ 的范围是 -1 到 1。

| 值 | 含义 |
| --- | --- |
| 1 | 方向完全一致（最相似） |
| 0 | 正交（无关） |
| -1 | 方向完全相反 |

余弦相似度只关心方向，不关心长度。一个短向量和一个长向量，如果方向一致，相似度仍然是 1。

## 为什么选余弦而不是欧氏距离

| 指标 | 关注点 | 适用场景 |
| --- | --- | --- |
| 余弦相似度 | 方向 | 文本相似度、推荐、语义搜索 |
| 欧氏距离 | 绝对距离 | 聚类、异常检测 |
| 曼哈顿距离 | 各维度绝对差之和 | 高维稀疏数据 |

在高维空间里，欧氏距离的区分度会下降（维度灾难）。余弦相似度因为归一化了长度，在高维空间表现更稳定。

## 实际应用

- **语义搜索**：把查询和文档都变成向量，用余弦相似度找最相关的文档。这就是 RAG 的检索环节。
- **推荐系统**：用户和物品各用一个向量表示，相似度高的物品推荐给用户。
- **去重**：两篇文章的向量相似度超过阈值，就可能是重复内容。
- **聚类**：在向量空间里用 K-Means 等算法把相似的数据分组。

## Python 示例

```python
import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

v1 = np.array([1, 2, 3])
v2 = np.array([2, 4, 6])  # 方向一致
v3 = np.array([3, -1, 0]) # 方向不同

print(cosine_similarity(v1, v2))  # 1.0
print(cosine_similarity(v1, v3))  # ≈ 0.08
```
