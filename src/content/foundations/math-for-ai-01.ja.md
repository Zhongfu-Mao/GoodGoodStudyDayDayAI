## なぜ AI にベクトルが必要か

AI モデルは、テキストや画像をそのまま理解することはできません。そのため、あらゆる情報を共通の形式である数値の配列（ベクトル）へと変換して処理を行います。ベクトル化することで、異なる種類のデータも数学的に扱えるようになります。

- 単語 → 300次元のベクトル
- 文章 → 768次元のベクトル
- 画像 → 2048次元のベクトル

重要なのは、単に情報を数値化することではなく、**「意味的に類似したデータが、ベクトル空間上でも近くに配置される」**という点にあります。

## ベクトル空間の直感的な理解

ベクトル空間は、多次元の座標系としてイメージできます。

- 2次元空間：各点は `(x, y)` で表される。
- 3次元空間：各点は `(x, y, z)` で表される。
- AI の Embedding 空間：数百から数千次元に及びますが、数学的な原理は同じです。

この空間内では、意味が近い概念ほど近い座標にマッピングされます。例えば、「猫」と「犬」のベクトル間の距離は、「猫」と「飛行機」の距離よりも大幅に短くなります。

## 内積とコサイン類似度

ベクトル空間において、2つのデータの類似度を測る最も一般的な指標がコサイン類似度（Cosine Similarity）です。

$$
\cos(\theta) = \frac{a \cdot b}{\|a\| \|b\|}
$$

ここで：
- $a \cdot b$ は内積（対応する要素同士を掛け合わせて合計した値）です。
- $\|a\|$ と $\|b\|$ はそれぞれのベクトルの長さ（ノルム）を表します。
- $\cos(\theta)$ の値は -1 から 1 の範囲に収まります。

| 値 | 意味 |
| --- | --- |
| 1 | 方向が完全に一致（最も類似している） |
| 0 | 直交している（無関係） |
| -1 | 方向が完全に逆（対照的） |

コサイン類似度の最大の特徴は、**ベクトルの「長さ」を無視し、「方向」のみに注目する**点です。文章の長さが違っても、内容の傾向が同じであれば類似度は 1 に近づきます。

## なぜユークリッド距離ではなくコサイン類似度なのか

| 指標 | 注目する点 | 主な適用シナリオ |
| --- | --- | --- |
| コサイン類似度 | 方向の一致度 | テキスト類似度、セマンティック検索、レコメンド |
| ユークリッド距離 | 空間上の絶対的な距離 | クラスタリング、異常検知 |
| マンハッタン距離 | 各次元の差の絶対値の合計 | 高次元の疎データ、グリッド上の移動 |

高次元空間においては、ユークリッド距離の識別力が低下する「次元の呪い」という現象が発生します。一方、コサイン類似度はベクトルの長さを正規化するため、高次元データに対しても安定した性能を発揮します。

## 実用例

- **セマンティック検索**：クエリと文書をベクトル化し、コサイン類似度で最も関連性の高いものを抽出。これが RAG（検索拡張生成）の基幹技術です。
- **レコメンドシステム**：ユーザーの嗜好ベクトルとアイテムのベクトルを比較し、類似度の高いものを推薦。
- **コンテンツの重複検出**：2つの記事のベクトル類似度が閾値を超えた場合に、重複コンテンツと判定。
- **自動クラスタリング**：ベクトル空間上で K-Means 等のアルゴリズムを用い、似た性質を持つデータをグループ化。

## Python による実装例

```python
import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

v1 = np.array([1, 2, 3])
v2 = np.array([2, 4, 6])  # v1 と同じ方向
v3 = np.array([3, -1, 0]) # v1 とは異なる方向

print(cosine_similarity(v1, v2))  # 結果: 1.0
print(cosine_similarity(v1, v3))  # 結果: ≈ 0.08
```

## 実務上の注意点

- **モデルの依存性**：Embedding モデルを変更すると、同じ文書でもベクトル空間の構造が変わるため、再計算が必要です。
- **閾値の調整**：類似度の閾値は一律に決めず、実際のデータの分布を確認しながら微調整を行うのが一般的です。
- **キーワード検索との併用**：短いクエリは情報量が少ないため、ベクトル検索だけでなくキーワード検索（BM25等）と組み合わせる「ハイブリッド検索」が有効です。
