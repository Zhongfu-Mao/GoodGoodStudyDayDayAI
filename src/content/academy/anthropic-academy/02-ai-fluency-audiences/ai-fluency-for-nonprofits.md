**面向对象**：非营利组织专业人员、社会服务工作者

> **课程核心**
> 非营利组织将 AI Fluency 应用于**使命驱动的工作**。核心理念：每一次 AI 效率提升，都应最终转化为**对社区更大的影响力（impact）**。

## 课程概述

本课程专为**非营利组织（Nonprofit）专业人员**设计，帮助他们将 AI Fluency Framework（4Ds）应用于实际工作，在提升组织效率与影响力的同时，保持与使命和价值观的高度一致。

**核心理念**：每一次 AI 效率提升，都应最终转化为对社区更大的影响力（impact）。

共9节课：
1. 欢迎与介绍
2. 4D 框架
3. 用 AI 进行研究（Description-Discernment 循环）
4. 用 AI 写作（Description-Discernment 循环）
5. 理解隐私与数据（Delegation-Diligence 循环）

7. 工作流增强（综合应用）
8. 整合：AI 融入组织
9. 下一步

## 一、AI Fluency 框架（4Ds）

### 定义
**能够有效（effectively）、高效（efficiently）、合乎伦理（ethically）、安全（safely）地与 AI 协作**的能力。

### 四个维度

| 维度 | 英文 | 在非营利场景中的含义 |
|------|------|---------------------|
| **授权** | Delegation | 决定哪些工作由人类完成，哪些可以委派给AI；包括Problem Awareness（了解问题）和Platform Awareness（了解工具） |
| **描述** | Description | 有效与AI沟通：Product Description（定义输出）、Process Description（描述步骤）、Performance Description（定义行为规范） |
| **辨别** | Discernment | 批判性评估AI输出：Product Discernment（评估质量）、Process Discernment（评估过程）、Performance Discernment（评估对象） |
| **勤勉** | Diligence | 对AI协作承担道德责任：Creation Diligence（创建时的审慎）、Deployment Diligence（部署时的监控）、Transparency Diligence（透明披露） |

### 两个循环

```
┌─────────────────────────────────────────┐
│       Delegation-Diligence Loop         │  ← 战略/伦理层：何时、是否用AI
│  ┌───────────────────────────────────┐  │
│  │   Description-Discernment Loop    │  │  ← 战术/执行层：如何有效用AI
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

## 二、建立组织上下文文档（Organizational Context Document）

### 为什么重要？
AI 不了解你的组织背景——每次从零解释背景效率低下，可复用的上下文文档让每次协作更高效。

### 关键领域（30分钟练习）

**第一步：自我反思（10分钟）**
- 组织的使命、愿景和价值观是什么？
- 你在组织中的角色和职责是什么？
- 核心工作哲学和方法是什么？
- *"如果AI能帮我___，我就能把更多时间用在___上。"*

**第二步：与AI对话协作**
覆盖关键领域：使命愿景、工作范围、典型挑战、机构限制、改善机会、痛点、AI融入目标、工作的独特性

**第三步：生成可复用文档**
要求AI将对话整合为结构化文档，格式便于在未来对话中复制复用。

## 三、Description-Discernment 循环应用

### A. 用 AI 进行研究（Researching with AI）

#### 核心要点

| 要点 | 说明 |
|------|------|
| **有效描述提供上下文** | 不只问宽泛问题——解释你是谁、你服务谁、你具体需要什么 |
| **辨别不可省略** | 必须批判性评估AI输出，尤其准确性至关重要时，标注具体声明进行核实 |
| **循环是迭代的** | 首次提示很少能满足需求，用评估反馈改进下一次描述 |
| **AI加速研究但不替代专业判断** | AI帮你快速入门，但你仍是必须运用专业知识做决策的人 |

#### 非营利常见研究场景

**政策与立法追踪**：
- 在提示中说明：你服务的人群、政策对使命的影响、需要了解的内容（影响、资金、合规、倡导）
- 评估时：识别需核实的声明、缺失的视角、过时信息

**捐助方/资助方研究**：
- 在提示中说明：使命与具体项目、组织规模/地区/服务人群、资助规模要求、何为"合适"的捐助方
- 评估时：核实捐助方是否资助同类规模的组织、核实截止日期和资格要求

### B. 用 AI 写作（Writing with AI）

#### 核心要点

| 要点 | 说明 |
|------|------|
| **上传过去的成功案例** | 帮助AI了解你的组织风格，节省时间，提高真实性 |
| **注入AI无法知道的细节** | 你的track record、合作关系、员工专业度、社区关系 |
| **具体说明修改意图** | 不说"让这更有说服力"，而说"加入这些关于我们社区关系的具体细节" |
| **让你的专业知识指导每次修改** | AI帮你写得更快，但你在塑造实质内容 |
| **建立认知环境** | 人机之间的来回对话让工具越来越适应你的具体需求 |
| **对最终结果负责** | 提交AI辅助的工作时，你应该能为每个字背书 |

#### 非营利常见写作场景

**拨款申请书（Grant Proposal）**：
- 提示需包含：资助机会和捐助方关注点、项目细节（服务对象/内容/地点/成果）、组织声音和价值观、具体要求（字数/必要元素/语气）、你的方法独特在哪里
- 辨别时：核实所有数据点和成果、检查语言是否符合组织实际声音、识别对受益人的歧视性措辞

**社交媒体帖子（Social Media Posts）**：
- 提示需包含：平台和格式、受众和驱动因素、核心信息和行动号召、组织社交媒体风格、视觉元素需求、限制条件
- 辨别时：检查语气是否匹配、核实数据准确性、评估语言对服务对象的尊重程度

## 四、Delegation-Diligence 循环应用

### A. 理解隐私与数据（Understanding Privacy & Data）

#### 核心要点

| 要点 | 说明 |
|------|------|
| **AI引入新的隐私考量** | 部分AI使用输入内容训练未来模型，你的数据模式可能影响后续输出 |
| **不同工具有不同规则** | 免费工具 ≠ 付费账户（数据保留政策不同） |
| **安全使用AI不是避免使用** | 而是负责任地使用——了解工具的数据政策 |
| **通常可以完全去除识别信息** | 用泛化标识符（Person A, Donor 1）替换姓名；剥离联系方式 |
| **出错后有补救选项** | 删除对话、通过平台隐私流程申请删除数据 |

**Claude 隐私设置**：详见 privacy.anthropic.com 和 trust.anthropic.com

#### 数据卫生（Data Hygiene）实践步骤
1. 将姓名替换为通用标识符（Person A, Donor 1等）
2. 去除或概化位置细节（如非必须）
3. 完全删除联系方式
4. 考虑具体金额是否需要精确，还是可以用区间

### B. 用 AI 进行数据分析（Data Analysis with AI）

#### 核心要点

| 要点 | 说明 |
|------|------|
| **用已知结果的数据测试AI** | 在用AI处理新分析前，用已知正确结果的历史数据验证AI能力 |
| **用辨别识别AI推理中的缺口** | 注意AI遗漏了哪些重要上下文，需要什么额外描述 |
| **建立经过验证的方法，而非盲目信任** | 每轮测试都告诉你AI在哪里做得好、在哪里需要引导 |
| **即使不懂数据分析，AI也能提供帮助** | AI可以帮助头脑风暴解决方案、写Excel公式等 |
| **验证建立信心，但不消除责任** | 你仍然需要确保结果有意义，对AI的角色保持透明 |

#### 非营利数据分析场景

**信息传播分析（Messaging Analysis）**：分析社交媒体、邮件等10-20个案例，识别高效内容的主题、语调和格式规律

**捐助方捐赠模式分析**：使用第5课的去识别化数据，分析捐助方留存率、周期性vs一次性捐赠、活动效果对比、按金额区间的捐赠趋势

**社区需求趋势分析**：收集项目数据、外部报告、新闻政策动态，识别需求变化趋势

## 五、工作流增强（Workflow Augmentation）

### 三种任务分类

| 分类 | 特征 |
|------|------|
| **AI可以处理** | 标准化回复、已记录的信息、清晰的流程 |
| **AI协助，人类决策** | AI起草/准备，人类审核后再行动 |
| **人类应处理** | 高风险决策、情感性情境、复杂判断 |

### 三类勤勉（Three Types of Diligence）

| 类型 | 关键问题 |
|------|----------|
| **Creation Diligence（创建）** | 为何这项任务适合AI处理？可能出什么错？ |
| **Deployment Diligence（部署）** | 是否审核每个输出？如何持续监控？何种情况暂停自动化？ |
| **Transparency Diligence（透明）** | 谁需要知道AI参与了？如何披露AI角色？ |

### 三类描述（Three Types of Description）

| 类型 | 说明 |
|------|------|
| **Product Description** | 最终结果是什么？输入和输出是什么？ |
| **Process Description** | 步骤是什么？决策点在哪里？何时升级给人类？ |
| **Performance Description** | 使用什么语调？如何处理不确定性？什么是绝对不能做的？ |

## 六、组织整合（Integration）

### 核心理念

| 要点 | 说明 |
|------|------|
| **"人类在环路中"的非营利含义** | 不只是监督，而是确保AI服务于你的使命——你决定AI应解决什么问题 |
| **通过理解避免依赖，而非回避** | 定期反思：我们能解释AI在做什么吗？如能，那就理解了 |
| **AI应让你有更多时间做更有人情味的工作** | 亲笔贺卡、个性化拓展、深度的社区关系——而非更少 |
| **尽早设定关于生产力的文化规范** | 讨论AI节省的时间如何重新分配 |
| **AI政策有助于扩展你的理解** | 文档化关于平台、任务委派、质量监督、透明度的决策 |

### 组织 AI 政策框架（7个部分）

```
Part 1: Platform Awareness（平台意识）
  └── 哪些AI工具可以用？哪些禁止？不同敏感度数据用什么工具？

Part 2: Task Delegation（任务委派）
  └── 哪些工作适合AI协助？哪些必须保持纯人类执行？灰色地带如何处理？

Part 3: Expectations & Capacity（期望与能力建设）
  └── AI节省的时间如何重新分配？如何在整个团队中建立AI能力？

Part 4: Quality & Oversight（质量与监督）
  └── 谁审核AI输出？不同类型内容需要什么验证步骤？出错时怎么办？

Part 5: Transparency（透明度）
  └── 利益相关方、资助方和服务对象需要了解哪些AI使用情况？

Part 6: Values Alignment（价值观对齐）
  └── 如何确保AI服务使命而非相反？在高效但不应使用AI时如何决策？

Part 7: Compile & Review（整合与复审）
  └── 与AI协作将答案综合成政策文件，定期复审并随组织发展更新
```

## 七、关键流程总结

```
AI Fluency for Nonprofits 核心框架

使命导向原则
└── 每次AI效率提升 → 最终转化为对社区更大的影响力

4D工作流（非营利应用）
├── Delegation: "应该用AI做这个吗？"而非"AI能做这个吗？"
├── Description: 上下文文档 + 三类描述（产品/过程/表现）
├── Discernment: 迭代评估 + 核实关键声明
└── Diligence: 三类勤勉（创建/部署/透明）

Description-Discernment 循环应用场景
├── 研究：政策追踪、捐助方研究
└── 写作：拨款申请、社交媒体内容

Delegation-Diligence 循环应用场景
├── 隐私：数据卫生、工具选择、风险评估
└── 数据分析：验证→分析→辨别（消息传播、捐助方模式、社区需求）

工作流增强
├── 三类任务：AI处理 / AI协助人类决策 / 人类独立处理
└── 三类描述：产品/过程/表现

组织整合
└── 7部分AI政策 + 文化规范 + 能力建设
```
