## まず一言で

Structured Output は、AI に表・JSON・番号リスト・分類ラベルなど、指定した形式で結果を出させることです。「一段の文章」ではなく「そのまま使えるデータ」として受け取れるようになります。

## なぜ自由文では足りないのか

AI のデフォルトは自然言語の段落です。簡単な Q&A なら問題ありませんが、次のような場合に困ります。

- 結果を Excel やデータベースに貼りたい。
- 別のプログラムに AI の出力を読ませたい。
- 複数回の結果を比較したい。
- 大きなタスクを標準化された小さなブロックに分けたい。

## よく使われる形式

| 形式 | 向いている場面 | 例 |
| --- | --- | --- |
| 表 | 比較、集計、分類 | 競合比較、機能一覧 |
| JSON | プログラム間のデータ受け渡し | API レスポンス、設定ファイル |
| 番号リスト | ステップ、優先度の整理 | タスク分解、チェックリスト |
| 分類ラベル | カテゴリ判定 | メール種別、感情分析 |
| Markdown | ドキュメント、レポート | 週報ドラフト、議事録 |

プログラミングを知らなくても、prompt で形式を指定するだけで使えます。

## 指定の仕方

prompt の末尾にフォーマットを書くだけです。

```text
表で出力してください。列は「名前」「利点」「欠点」「向いている場面」。
```

コツ：

- 具体的な例を一つ見せると AI が真似してくれる。
- フィールド名とデータ型を明示する。
- 出力がずれたら、どこを直すか指示して再生成。

## エンジニア以外でも役立つ

- 調査メモを表に整理して会議で見せる。
- 「優先度 / 担当 / 期限」形式でタスクを出力。
- 統一テンプレートで複数の返信メールを生成。
- 「論点→根拠→結論」構造で分析を出力。

## やってみよう

ChatGPT や Claude で試してみてください。

**実験 1**：`個人向けの AI ツールを 3 つ紹介してください。`

**実験 2**：
```text
個人向けの AI ツールを 3 つ紹介してください。
表で出力し、列は「ツール名」「主な機能」「無料枠」「向いている人」にしてください。
```

どちらがそのままドキュメントに貼れるか比べてみてください。

## 実用的な見方

AI に出力を頼むときは、まず次を考えてください。

1. 結果を受け取った後、何をするか。
2. 自由文で足りるか、構造化が要るか。
3. 他の人やツールが結果を使うか。
4. 複数回の結果を比較するなら、どの形式が便利か。

「出力の使い道を先に決めてから prompt を書く」習慣をつけると、やり直しが大幅に減ります。
