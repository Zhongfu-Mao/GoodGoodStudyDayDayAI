## 本路线解决的核心问题

OpenAI Academy 的公开内容覆盖面极广，涵盖了从 AI 基础概念、ChatGPT 日常使用、行业办公场景、教育应用，到 Codex 开发及 AI 系统构建等多个领域。相较于单一课程，它更像是一组持续更新的学习入口。

本站将其整合为一条循序渐进的学习路径：

1. **建立总览**：明确 OpenAI Academy 的教学体系与目标。
2. **夯实基础**：通过 AI Fundamentals 建立完整的概念地图。
3. **优化工作流**：学习 Using ChatGPT，将一次性对话转化为可复用的专业方法。
4. **任务交付**：深入学习 Codex，实现从“对话”到“自动化交付”的跃迁。
5. **系统构建**：探索 Building with AI，将工具使用能力沉淀为系统化的构建能力。
6. **专题补齐**：横向扩展工作与教育等垂直领域的专项应用。

## 官方内容框架解读

OpenAI Academy 的主入口目前将内容分为七大类别：

| 模块 | 核心定位与理解 |
| --- | --- |
| AI fundamentals | 为非技术读者提供的基础地图，涵盖 AI 原理、模型机制、OpenAI 产品线及责任使用原则。 |
| Using ChatGPT | 从基础 Prompt 进阶到 Projects、Custom GPTs、Skills 及 Workspace Agents 等深度工作流。 |
| ChatGPT for work | 针对不同角色（Role）、行业（Industry）及常见任务组织的办公应用实战。 |
| ChatGPT for education | 面向 K-12、高等教育、教职员工及校园运营的专项应用场景。 |
| Codex | 专注于开发任务、代码自动化及技术工作流的深度学习入口。 |
| Codex for work | 面向非开发场景的 Codex 应用，强调通过文件与工具协作完成复杂任务。 |
| Building with AI | 从工具使用迈向 AI 系统构建，涵盖技术路线图、评估体系及可复用架构模式。 |

## 阅读建议与学习路径

**1. 快速上手路径（推荐）**：
`AI Fundamentals` → `Getting Started with ChatGPT` → `Prompting Fundamentals` → `Working with Files` → `Research with ChatGPT` → `Writing with ChatGPT` → `Codex`。

**2. 职场提效路径**：
直接从 `ChatGPT for Work` 开始，按角色（如营销、财务、运营等）挑选相关页面，无需完全按顺序阅读。

**3. 开发者/系统构建路径**：
优先切入 `Codex` 和 `Building with AI`，随后回头补齐 `Evals`、`RAG`、`Agents` 等工程化专题。

**4. 教育/学术路径**：
重点阅读 `ChatGPT for Education`，涵盖教师教学、学生学习及课程设计等维度。

### 学习定位

本页为 **OpenAI Academy 学习路线总览**。它面向希望系统化掌握 OpenAI 工具链、优化工作流并构建 AI 应用的读者。重点在于建立系统视角，将零散的功能点转化为可复用的专业能力。

### 学习目标

- 将 OpenAI Academy 视为一份动态的学习地图，而非孤立的文章清单。
- 遵循“基础认知 -> 深度使用 -> 场景适配 -> 系统构建”的成长路径。
- 为后续的个人实践记录预留接口，实现“资料消化”与“经验沉淀”的良性循环。

### 实操工作流建议

1. **定位现状**：确认自己处于“入门使用者”、“团队推动者”还是“AI 开发者”阶段。
2. **任务驱动**：每阅读一个模块，尝试解决一个真实的小任务，并记录结果。
3. **沉淀工具**：将高频任务转化为 Project、Custom GPT 或专用 Skill。
4. **风险管控**：针对行业/教育场景，优先建立人工复核与安全边界机制。
5. **闭环复盘**：定期回到总览页，根据实践反馈调整学习重点。

- **事实性**：输出是否严格基于提供或可溯源的信息，避免推断性陈述。
- **确定性**：是否明确标出了模型不确定、需人工判断或待确认的部分。
- **落地性**：是否提供了明确的“下一步动作”，而非空泛的文字。
- **合规性**：是否符合特定行业或组织的隐私与数据安全要求。
