**说明：** 本文整理图像生成工作流，重点是怎么把视觉需求说清楚。

## 这节课解决什么问题

图像生成不是写越长越好，而是把目的、主体、动作、场景、风格和限制说清楚。尤其在需要编辑已有图像时，要明确哪些东西改变，哪些保持不变。

## 图像 prompt 的六个要素

| 要素 | 问题 |
| --- | --- |
| 目的 | 这张图用在哪里 |
| 主体 | 画面中心是什么 |
| 动作 | 主体在做什么 |
| 场景 | 时间、地点、环境 |
| 风格 | 摄影、插画、写实、极简等 |
| 约束 | 不要文字、不要 logo、保持构图等 |

## 迭代方法

不要一次要求模型把所有细节做到完美。更稳的流程是：

1. 先生成方向草图。
2. 选择一张最接近的版本。
3. 每轮只改一个维度，比如亮度、构图、背景、色彩。
4. 如果编辑已有图片，明确“只改 X，其余保持不变”。
5. 如果需要文字，尽量短，并给出位置、字号、字体风格。

## 使用边界

涉及真人肖像、品牌、受版权保护的风格、医疗金融等敏感用途时，需要额外谨慎。公开站点素材更推荐生成通用、可拥有、没有品牌混淆的视觉资产。

## 本站用途

可以用它生成 Academy 封面图、Radar 信息图草稿和文章配图方向。但对于正式发布的图像，我仍然会加一道人工视觉 QA，避免文字错误、布局拥挤和不合适的视觉暗示。



## 完整版学习稿

### 学习定位

这一页可以当作 **Creating Images with ChatGPT** 的系统学习稿。它面向想用 AI 生成教学、营销、博客或产品视觉草案的人，重点不是背官方术语，而是把页面里的能力、场景和边界转成可以反复使用的工作方法。

### 学习目标

- 把图像生成看成创意迭代流程，而不是一次性抽奖。
- 学会描述主体、构图、风格、用途和限制。
- 能把生成结果转成后续修改指令。

### 官方内容拆解

| 模块 | 学习重点 | 可产出材料 |
| --- | --- | --- |
| 用途 | 图片要服务什么内容或场景 | 封面、插图、流程图、概念图 |
| 画面要素 | 主体、动作、环境、构图、比例 | 更可控的生成指令 |
| 风格约束 | 真实感、插画、品牌感、颜色、材质 | 视觉一致性 |
| 迭代反馈 | 指出保留和修改部分 | 第二版、第三版改稿 |

### 实操工作流

1. 先写清图片用途和读者。
2. 描述主体、场景、构图和尺寸比例。
3. 给风格参考但避免侵犯他人风格或版权。
4. 生成后用具体反馈迭代。
5. 发布前检查文字、事实、品牌和版权边界。

### 可复用 Prompt

```text
请为[文章/课程/产品]生成一张图片。用途是[用途]，主体是[主体]，构图为[构图]，风格是[风格]，尺寸比例为[比例]。请避免[限制]，并保留可用于后续修改的设计说明。
```

### 复核清单

- 输出是否只使用已提供或可追溯的信息，不把推断写成事实。
- 是否标出不确定性、待确认项和需要人工判断的地方。
- 是否给出可执行的下一步，而不是只生成漂亮文字。
- 是否符合团队、学校、公司或行业的隐私与合规要求。

学完这一页，最好不要只留下摘要，而是留下 一份可复用的学习笔记、prompt 模板和实践清单。如果以后要补自己的课程心得，可以在这份材料后面继续追加：真实使用场景、失败案例、改进后的 prompt、以及哪些判断必须由人完成。
