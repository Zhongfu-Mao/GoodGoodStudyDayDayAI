**注記：** 本ページは OpenAI Academy の公開情報に基づき構成された学習ノートです。Projects を単なる「フォルダ」ではなく、AI との対話を深める「共同作業スペース」として活用するための視点を提供します。

## 概要：単発の対話から継続的なプロジェクトへ

通常のチャットは一過性のタスクに適していますが、Projects は長期間にわたるテーマや反復的な業務に最適です。関連するドキュメント、独自の指示、そして過去の対話履歴を一箇所に集約することで、ChatGPT はプロジェクトの背景を深く理解し、常に一貫したトーンで回答できるようになります。

## Projects を導入すべき 5 つのケース

| ケース | Projects を使うメリット |
| --- | --- |
| **長期的なリサーチ** | 関連資料が蓄積されるほど、回答の精度と網羅性が向上する。 |
| **コンテンツ制作** | トーン＆マナーや構成案を共有し、一貫したブランドボイスを維持できる。 |
| **学習・研究計画** | シラバスや参考文献を保持し、進捗に合わせた個別指導が可能。 |
| **チーム連携** | 共通の知識ベース（事実情報）に基づき、チーム全体で高品質な出力を得られる。 |
| **定型業務の自動化** | 毎週・毎月の定型フォーマットを保持し、過去の記録を参照した更新が可能。 |

## プロジェクトを成功させる「3 つの資産」

1. **プロジェクト指示 (Project Instructions)**：目的、ターゲット、文体、避けるべき表現などの「基本方針」。
2. **ナレッジベース (Knowledge Base)**：参考にする文書、データ、ガイドラインなどの「事実情報」。
3. **継続的な文脈 (Context Flow)**：これまでの決定事項や未解決の課題といった「進行状況」。

## Custom GPTs および Skills との使い分け

- **Projects**：特定の「プロジェクト」や「期間」に紐づく**コンテキスト**の管理。
- **Custom GPTs**：特定の「役割」や「専門性」に特化した**人格（エージェント）**の定義。
- **Skills**：特定の「手順」や「フォーマット」に従う**ワークフロー**の標準化。

**実務のコツ：** まずは Project で情報を整理し、その中で定型化されたタスクが見えてきたら、それを実行するための「Skill」を定義するのが効率的です。
