## 本モジュールが解決する課題

実務におけるライティングの難所は、単なる「言葉選び」ではなく、**目的、対象（ターゲット）、構造、そして次のアクション**が不明確であることに起因します。ChatGPTは、粗い素材を「レビュー可能な草案」へと昇華させる作業に最適ですが、最終的な判断と責任は常に人間が担う必要があります。

## ライティングの4ステップ・ワークフロー

| ステップ | 核心となる目標 |
| --- | --- |
| **Plan（計画）** | 「誰に」「何を」「なぜ」伝え、どのような行動を促したいかを定義します。 |
| **Draft（起草）** | 最初の草稿を迅速に生成し、白紙から書き始めるストレスを排除します。 |
| **Revise（推敲）** | 論理性、トーン、長さ、明快さを調整し、品質を高めます。 |
| **Package（加工）** | メール、メモ、FAQ、スライド用スクリプトなど、配信チャネルに合わせた形式に整えます。 |

## 実務で使えるプロンプト・テンプレート

```text
指示：以下の素材をもとに [出力形式] を作成してください。
ターゲット：[誰が読むか]
目的：[読了後にどのような理解・決定・行動を期待するか]
制約条件：
- 必須要素：[事実、数値、必須の制限事項]
- 禁止事項：[機密情報、専門用語の多用、誇張表現]
進め方：まず「構成案」を提示し、私の承認後に「本文」を作成してください。
```

## 深度解説：タスクからワークフローへの転換

OpenAIのガイドでは、実務ライティングを以下の実戦的なパスに集約しています。

```text
Plan -> Draft -> Revise -> Package
```

**実務における解釈：**

| フェーズ | 重要な問い |
| --- | --- |
| **Plan** | この文章が存在する意義は何か？ 読者に期待する「次の一手」は何か？ |
| **Draft** | 断片的な素材を、編集可能な「第1稿」へ最速で変換する。 |
| **Revise** | 論理の飛躍はないか？ トーンは適切か？ 不要な箇所を削ぎ落としたか？ |
| **Package** | チャネル（Slack、メール、資料）に合わせた最適なフォーマットになっているか？ |

この手法の最大の利点は、ライティングを属人的な「センス」ではなく、再現可能な「プロセス」に変える点にあります。

## 適応範囲の境界線

- **適した場面**：会議のフォローアップ、エグゼクティブ・サマリー、手順書、告知の草案、複数トーンのバリエーション作成。
- **適さない場面**：事実確認（ファクトチェック）前の声明、法的・コンプライアンス上の厳密さが求められる対外文書、組織の最終的な立場を代表する公式声明。



## 完全版学習ノート

### 学習の位置づけ

本ページは **Writing with ChatGPT** の体系的な学習ガイドです。日常的にメール、メモ、報告書、FAQ、プレゼン資料を作成する方を対象としています。機能の習得にとどまらず、入出力、制約、評価を一つの「型」として定着させることを目指します。

### 学習ゴール

- 「書き始める」前のストレスを、Plan -> Draft -> Revise -> Package の協働モデルで解消する。
- 事実の決定は人間が行い、構成や表現の最適化をAIに委ねる役割分担を確立する。
- 対外文書や機密情報を扱う際の、厳格な複認（ダブルチェック）習慣を身につける。

### コンテンツの分解

| セクション | 学習の重点 | 期待される成果物 |
| --- | --- | --- |
| **Plan** | 目的、読者、CTA（コール・トゥ・アクション）の定義。 | ライティング・ブリーフ、構成案。 |
| **Draft** | 素材を最速で第1稿に変換。 | メール、メモ、告知、スクリプト。 |
| **Revise** | 明快さ、トーン、長さ、ロジックの最適化。 | 短縮版、フォーマル版、顧客向け版。 |
| **Package** | チャネル適応と形式の微調整。 | メールの件名、FAQ、スライド用テキスト。 |

### 実践ワークフロー

1. **前提の定義**：ターゲットと目的を一文で言語化する。
2. **素材の提供**：生の素材、必須要素、および「禁止事項」を列挙する。
3. **構成優先**：いきなり書かずに、まず「ロジック構造」を確認する。
4. **段階的な修正**：一度に多くを求めず、「長さ」「トーン」など一軸ずつ調整する。
5. **最終複認**：事実、トーン、責任の境界線を人間が最後に確認する。

### 再利用プロンプト案

```text
以下の素材を[出力形式]にまとめてください。ターゲットは[読者]、目的は[ゴール]です。
まず構成案を提示し、事実のみを保持して未知の情報を補完しないでください。
最後に、人間が確認すべき「不確実な点」をリストアップしてください。
```
