**说明：** 本文旨在梳理数据分析场景下 ChatGPT 的协作模式，强调其作为“分析助手”的定位，而非替代最终的审计与专业判断。

## 本模块解决的核心问题

数据工作的瓶颈往往出现在初始阶段：面对海量表格，不知从何入手、难以识别关键维度、忽视了异常数据的信号。ChatGPT 的价值在于协助你快速完成数据探索（EDA）、生成可视化方案建议、并将复杂分析结果转化为可读性强的商业洞察。

## 黄金准则：从业务决策出发

不要以“帮我分析这个表”作为对话的开始，而应遵循以下逻辑：

```text
背景：我想基于 [业务场景] 做出关于 [具体决策问题] 的判断。
数据源：当前数据来自 [来源/时间范围]，包含 [关键字段说明]。
任务：
1. 请先进行 EDA（探索性数据分析），总结关键字段分布、缺失值情况及潜在异常点。
2. 提出 3-5 条可能的分析路径，并说明理由。
3. 暂时不要给出最终结论，请先列出你需要我补充确认的假设条件。
```

## 标准分析五步法

1. **定义决策场景**：明确分析是为了支持哪项业务行动。
2. **数据质量评估**：提供数据字典，由模型进行完整性与合规性检查。
3. **方法论同步**：先确认分析思路与计算逻辑，再执行运算。
4. **多维可视化**：明确需要对比的维度（如时间、地区、品类）及推荐图表。
5. **行动摘要输出**：产出可复用的数据表、洞察摘要及后续追问清单。

## 场景切入：何时使用 ChatGPT？

官方指南强调：ChatGPT 最擅长的是**数据分析的早期探索阶段**。

- **对比 BI 仪表盘**：BI 仪表盘适合监控固定、成熟的指标；ChatGPT 适合探索未知、解释波动、以及将枯燥的数据“翻译”为非技术背景同事能读懂的策略摘要。

## 阶梯式练习建议

上传一份 CSV 文件后，尝试以下递进式指令：

1. **初步画像**：该数据集包含哪些核心字段？它们在业务逻辑中可能代表什么？
2. **质量扫描**：识别数据中的缺失值、异常极大值或格式不一致项。
3. **视角挖掘**：针对我的业务目标，请提供 3 个最具洞察力的分析视角。
4. **最小化验证**：请先执行一项核心维度的交叉分析，并标注结论的不确定性。
5. **决策摘要**：将以上分析结果提炼为给业务决策者看的行动建议。

## 风险防控与人工复核

模型可能误解特定领域的列含义、忽视底层的数据质量陷阱、或过度解读相关性。

**必须人工复核的环节：**
- 涉及财务结算、严谨实验结论、医疗诊断或重大商业并购的决策逻辑。
- 复杂的统计学推断（相关性 vs 因果性）。
- 数据样本的代表性评估。



## 完整版学习稿

### 学习定位

本页为 **Analyzing Data with ChatGPT** 系统化学习稿。它面向希望利用自然语言辅助数据探索、解释与汇报的职场人士。核心在于建立“数据驱动决策”的思维，而非单纯掌握 Prompt 技巧。

### 学习目标

- 确立“决策导向型”分析流程。
- 养成“先评估数据质量，再进行深度挖掘”的职业习惯。
- 提升将数据洞察转化为行动方案（Actionable Insights）的能力。

### 官方内容拆解

| 模块 | 学习重心 | 代表性产出物 |
| --- | --- | --- |
| **Data orientation** | 明确字段口径、时间跨度、缺失值风险。 | 数据字典、数据质量评估报告。 |
| **EDA** | 发现分布特征、异常模式与潜在趋势。 | 探索性分析简报、可视化草案。 |
| **Hypothesis** | 探究现象背后的潜在原因。 | 待验证业务假设列表。 |
| **Action summary** | 面向非技术受众的洞察解读。 | 决策支持摘要、下一步行动建议。 |

### 标准实操流

1. **背景锚定**：说明需要支持的业务决策目标。
2. **定义边界**：提供字段定义与业务口径约束。
3. **分阶段执行**：坚持“质量检查 -> 分析计划 -> 图表产出 -> 洞察提炼”的顺序。
4. **逻辑解构**：要求模型区分相关性、可能原因与待验证假设。
5. **结论复核**：输出中必须包含对限制条件与潜在误差的说明。
