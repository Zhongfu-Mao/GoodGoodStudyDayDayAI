**说明：** 本文整理销售与业务开发团队的 AI 应用路径。

## 核心价值

销售工作的瓶颈往往在于前期的账户研究、繁重的商谈准备、高频的客户跟进以及复杂的内部协同。ChatGPT 可以将海量的账户资料、通话记录、CRM 信息及产品素材快速转化为可行动的产出，从而让销售人员将核心精力回归到与客户的深度对话中。

## 典型应用场景

| 场景 | 核心产出建议 |
| --- | --- |
| **账户研究 (Account research)** | 账户简报 (Brief)、行业背景深度分析、干系人影响力假设 |
| **需求挖掘 (Discovery)** | 引导式问题清单、资质评估 (Qualification) 摘要、潜在风险信号 |
| **商谈准备 (Meeting prep)** | 会议议程、预读材料要点、会后即时行动项 |
| **客户触达 (Outreach)** | 个性化邮件话术、LinkedIn 社交信息、跟进策略建议 |
| **方案设计 (Proposal)** | 核心价值主张、ROI 逻辑结构、执行摘要 (Executive Summary) |
| **交易管理 (Deal management)** | 共同行动计划 (MAP)、成交推进计划、下一步策略建议 |

## 推荐销售 Prompt

```text
请基于提供的账户资料，生成一份 1 页规模的商谈准备单 (Sales Call Prep)。
要求包含：客户背景概述、潜在业务痛点、需验证的关键假设、3 个深度需求挖掘问题 (Discovery Questions)、会后跟进邮件模板。
请勿编造客户事实；对于不确定的信息，请统一标注为“待确认”。
```

## 风险提示

销售内容最忌讳“泛泛而谈”与“过度承诺”。所有涉及客户事实、竞品对比话术、价格策略及安全合规的答复，均需经过人工严格复核，确保信息的保真度与合规性。

## 完整版学习稿

### 学习定位

本章节可作为 **ChatGPT for Sales Teams** 的系统化学习指南。它面向销售人员 (AE)、业务开发 (SDR/BDR)、售前顾问及客户拓展团队，重点在于利用 AI 实现从潜客研究到交易执行的全链路标准化。

### 学习目标

- 实现账户研究、会议筹备、客户跟进及交易协同的流程标准化。
- 熟练利用模型整理 CRM 数据、商谈记录及公开财报资料，杜绝信息编造。
- 通过提效辅助工具，将更多时间分配给真实的客户互动。

### 官方内容拆解

| 模块 | 学习重点 | 核心交付物 |
| --- | --- | --- |
| **Account research** | 公司战略、行业动态、干系人矩阵、触发事件分析 | 账户简报 (Account Brief) |
| **Discovery** | 痛点识别、成功标准定义、成交阻碍分析 | 问题指引手册 |
| **Meeting follow-up** | 通话要点提取、行动项指派、责任人明确 | 会后总结邮件 (Recap Email) |
| **Proposal** | 商业价值、ROI 模型、实施路径规划 | 方案大纲/建议书 |
| **Deal management** | 关键里程碑、风险预警、内部资源协同 | 共同行动计划 (MAP) |

### 实操工作流

1. **背景梳理：** 汇总账户历史资料与过往互动记录。
2. **策略制定：** 利用模型生成商谈准备单 (Call Prep) 与待验证的业务假设。
3. **即时复盘：** 会后迅速将 Notes 转化为结构化的总结与行动建议。
4. **方案适配：** 针对客户的特定语言和业务逻辑，改写建议书与价值模型。
5. **动态监控：** 定期更新交易风险、责任人状态及下一步推进计划。

### 推荐 Prompt

```text
请基于以下账户背景生成商谈准备单：客户战略重心、潜在业务挑战、待验证假设、深度挖掘问题、潜在风险信号及会后跟进模板。请确保不编造任何客户事实。
```

### 复核清单

- 输出内容是否严谨遵循已知素材，有无将 AI 的逻辑推论误当作客户的实际表态？
- 是否明确标注了信息中的模糊地带及需在商谈中实地确认的环节？
- 是否给出了具备极高执行性的下一步建议，而不仅是优美的书面修辞？
- 内容是否符合公司关于客户数据保护的隐私规范及销售合规准则？

### 学习成果沉淀

完成本章学习后，建议沉淀一套覆盖不同销售阶段（如首次接触、深度方案、商务谈判）的专属 Prompt 库。通过不断补充“高转化话术案例”来训练模型的语调一致性。

## 官方 Use Cases 深度解析

官方 Sales 页面覆盖了从线索开拓 (Prospecting) 到交易执行 (Deal Execution) 的完整闭环。

| 领域 | 常见应用场景 | ChatGPT 产出建议 | 销售专业复核点 |
| --- | --- | --- | --- |
| **开拓与账户研究** | 账户深度研究、行业趋势、干系人地图 | 账户简报、干系人假设、切入角度建议 | 账户真实优先级与组织内部政治关系 |
| **需求挖掘与评估** | 准备 Discovery、明确场景与成功标准 | 挖掘指引、资质评估摘要、风险红旗 (Risk Flags) | 客户痛点的真实性与预算的紧迫度 |
| **会议准备与复盘** | 赛前演练、会后结构化整理 | 议程、通话摘要、行动项、跟进邮件 | 下一步动作的具体性与责任归属 |
| **触达序列设计** | 邮件序列、LinkedIn、多触点节奏规划 | 主题行、序列草案、常见异议处理片段 | 模板化程度控制、相关性与针对性 |
| **方案与商业案例** | 价值表达、ROI 建模、方案包装 | 方案大纲、ROI 模型结构、执行摘要 | ROI 假设的合理性、合同与承诺边界 |
| **交易过程管理** | 跟踪进展、协调内外部资源 | 决策日志、干系人同步更新、推进计划 | 真实成交意愿评估、被低估的阻碍因素 |

核心思路：好的销售应用方式应始终围绕“客户具体情境”、“客户真实语言”以及“可落地的下一步行动”展开，避免落入“AI 生成的通用套话”陷阱。

## 原创学习增强包

### 三阶实践路径

| 阶段 | 实践任务 | 核心交付物 |
| --- | --- | --- |
| **轻量体验 (30 min)** | 阅读本页并对比官方来源，提炼 5 条能立即优化下一场商谈准备的行动建议。 | 一份“销售 AI 助跑”清单 |
| **深度实操 (2 hr)** | 选取一个目标账户，模拟从财报研究到起草首封个性化邮件的完整流程。 | 一份完整的账户渗透计划 |
| **进阶定制 (0.5 day)** | 将实操经验转化为团队共享的“销售 Prompt 百宝箱”，并建立话术合规红线检查。 | 团队专属 Sales Prompt Pack |

### 虚构案例模拟

**情境：** 销售人员准备拜访虚构客户 BlueRiver Ops，需进行深度需求挖掘、会后跟进及内部同步。
**输入设定：** 财报摘要、行业大背景、过往互动记录、产品核心价值、本次商谈目标。
**产出目标：** 账户简报、挖掘问题指引、个性化跟进邮件、交易风险分析。

### 原创 Prompt Pack

1. “请为该目标账户生成一份具备战略深度的商谈准备单。”
2. “请设计 8 个进阶挖掘问题，并注明每个问题背后旨在验证的业务假设。”
3. “请将这段未经整理的通话记录转化为具备强烈‘下一步动作’导向的客户邮件。”
4. “请为内部同步会议撰写一份交易简报，重点列出当前的成交阻碍与风险。”
5. “请核查此方案中是否存在过度承诺、泛化话术或不符合合规要求的描述。”

## 亲测记录模板

> **实践建议：** 记录时侧重于账户洞察的精准度、客户话术的转化力以及交易推进的节奏感，隐去具体的合同金额和未公开的内部联系人信息。

### 实践记录表

| 记录项 | 填写指南 |
| --- | --- |
| **学习动机** | 该模块如何助力缩短销售周期或提升赢单率？ |
| **输入素材类型** | 列出所用材料（如客户官网、三方财报分析、CRM 通话转写等）。 |
| **第一版 Prompt** | 记录初始指令，重点观察 AI 对客户痛点的敏感度。 |
| **输出偏差记录** | 记录模型在事实归纳、语气拿捏或竞争对手判断上的偏差。 |
| **纠偏策略** | 你是通过提供更细的业务约束、引入高赢单案例还是限定受众画像来优化的？ |
| **最终交付物** | 沉淀为可复用的账户研究模板、方案大纲框架或跟进序列模板。 |
| **人工复核结论** | 明确标注哪些洞察可直接引用，哪些必须在现场面谈中进行二次确认。 |
| **经验分享点** | 总结脱敏后的“销售 AI 实战心得”、高转化 Prompt 技巧或协同推进建议。 |
