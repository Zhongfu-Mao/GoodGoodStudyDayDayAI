## コア・バリュー

営業業務のボトルネックは、リサーチ、資料準備、フォローアップ、そして社内調整に費やされる膨大な時間にあります。ChatGPTを活用することで、アカウント情報、商談ログ、CRMの記録、製品資料を「即座に実行可能なアウトプット」へと変換できます。これにより、営業担当者は顧客との対話という最も付加価値の高い業務に集中できるようになります。

## 典型的な活用シーン

| シーン | ChatGPTによるアウトプット例 |
| --- | --- |
| **アカウント・リサーチ** | アカウント・ブリーフ、業界背景、ステークホルダーの仮説整理 |
| **ディスカバリー** | 質問リスト、クオリフィケーション (Qualification) サマリー、リスク兆候 |
| **商談準備** | 会議アジェンダ、事前配布資料、アクションアイテム案 |
| **アウトリーチ** | パーソナライズされたメール、LinkedInメッセージ、フォローアップ話法 |
| **提案・ソリューション** | 価値提案の構成、ROIシミュレーションの骨子、エグゼクティブ・サマリー |
| **ディール管理** | 相互アクションプラン (MAP)、クローズ計画、次のステップの推奨案 |

## 効果的な営業プロンプトの例

```text
以下の提供資料に基づき、1ページの商談準備シートを作成してください。
構成：
1. 顧客の背景と想定されるペインポイント
2. 検証すべき3つの仮説
3. ディスカバリー用の質問リスト（5つ）
4. 商談後のフォローアップメールのテンプレート
※顧客の事実を捏造せず、不確かな箇所は「要確認」と明記してください。
```

## リスクと留意点

営業におけるAI活用で最も避けるべきは「汎用的な定型文」と「過度な約束」です。顧客に関する事実関係、競合比較の主張、価格、セキュリティ要件などは、必ず人間が最新の情報と照らし合わせてレビューする必要があります。

## 完全版学習ノート

### 学習の位置づけ

本セクションは、**ChatGPT for Sales Teams** を体系的に学ぶためのガイドです。営業（AE/SDR）、プリセールス、BD、アカウントマネジメントチームを対象としています。リサーチからディール締結までの各工程を標準化し、AIを「営業のパーソナル・アナリスト」として活用する手法を習得します。

### 学習ゴール

- アカウント・リサーチ、商談準備、フォローアップ、ディール管理の各工程を型化する。
- CRM、録音ログ、公開資料をAIで整理させ、事実に基づいた提案の質を上げる。
- 定型業務を効率化し、顧客との対話時間を最大化する。

### 公式コンテンツの分解

| モジュール | 学習のポイント | 具体的な成果物 |
| --- | --- | --- |
| **Account Research** | 企業、業界、キーマン、トリガーイベントの把握 | アカウント・ブリーフ |
| **Discovery** | ペインポイント、成功基準、リスクの特定 | 質問ガイド |
| **Follow-up** | 商談サマリー、アクションアイテム、責任の明確化 | リキャップ・メール |
| **Proposal** | 価値、ROI、導入ロードマップの提示 | プロポーザル構成案 |
| **Deal Management** | 次のステップ、リスク、社内連携の最適化 | 相互アクションプラン (MAP) |

### 実践ワークフロー

1. **インプット：** 顧客資料とこれまでのインタラクション履歴を整理します。
2. **プランニング：** AIを使って商談準備シート (Call Prep) と検証仮説を出力します。
3. **エグゼキューション：** 商談後、メモを即座にサマリーとアクションアイテムに変換します。
4. **カスタマイズ：** 顧客の言葉や課題に合わせて、提案書やROIモデルを書き換えます。
5. **モニタリング：** リスクやステークホルダーの変化を定期的に更新し、プランを修正します。

### 推奨プロンプト

```text
以下の顧客情報に基づき、商談準備シートを作成してください。顧客の背景、想定課題、検証すべき仮説、ディスカバリー用質問、リスク兆候、およびフォローアップメールの案を含めてください。事実の捏造は厳禁とし、不明点は要確認事項としてリストアップしてください。
```

### 確認チェックリスト

- 出力は提供された事実に基づいているか？（顧客の業績や課題を勝手に作っていないか）
- 抽象的な営業トークではなく、顧客固有の状況に基づいた「次のアクション」が示されているか？
- 価格、納期、機能などの重要な約束事項に、不確実な点が含まれていないか？
- 顧客の機密情報や個人情報の扱いに、組織のポリシー上の問題はないか？

### 学習の資産化

学習後は、自社の製品価値や成功事例を組み込んだ「営業専用プロンプト集」をストックしてください。また、AIが作成したドラフトを顧客の心に響く言葉へどう磨き上げたか、その修正プロセスこそがチームの共有財産になります。

## 公式ユースケースの詳細解説

公式のSalesページでは、プロスペクティング（見込み客開拓）からディールの実行まで、営業活動の全方位をカバーしています。

| 領域 | 活用シーン | 推奨されるアウトプット | 営業担当者が補うべき判断 |
| --- | --- | --- | --- |
| **Prospecting & Research** | ターゲット選定、アカウント深掘り、キーマン分析 | アカウント・ブリーフ、攻略アングル案 | 真の優先順位と内部の人間関係 |
| **Discovery & Qual** | 課題ヒアリング準備、成功基準の合致確認 | ディスカバリーガイド、BANTサマリー | 顧客が「本当に」痛みを感じているか |
| **Meeting Prep & Debrief** | 会前予習、会後アクション整理 | アジェンダ、商談記録、リキャップメール | 次のステップの具体性と合意度 |
| **Outreach Sequences** | マルチチャネル・アプローチの設計 | メール件名、メッセージ案、反論処理 | 相手にとっての妥当性とタイミング |
| **Proposal & ROI** | ビジネスケースの構築、ROIシミュレーション | 提案書構成、ROIモデル、サマリー | 数値仮説の妥当性と価格の妥当性 |
| **Deal Management** | 進捗管理、社内リソースのコーディネート | 決定事項ログ、MAP、ステークホルダー更新 | 案件の勝算 (Commitment) と隠れたリスク |

重要なのは「パーソナライズされているように見える汎用テンプレート」に陥らないことです。AIはあくまでインプットされた「顧客固有のコンテキスト」を整理する道具として使いましょう。

## オリジナル学習強化パック

### 三段階の実践ステップ

| 段階 | 実践タスク | 成果物 |
| --- | --- | --- |
| **クイック・スタート (30分)** | 本ページを確認し、直近の商談準備をAIを使って「検証仮説付き」で作成する。 | 商談準備シート (Call Prep) |
| **ディープ・ダイブ (2時間)** | 架空のアカウント（または脱機密化した実在案件）で、リサーチから提案構成案までを完結させる。 | ディール攻略プラン |
| **ナレッジ化 (半日)** | チーム内で成果の出たアウトリーチ文面や、ROI構成案をプロンプト化して共有する。 | チーム専用 Sales Prompt Pack |

### ケーススタディ

**シナリオ：** ターゲット顧客「BlueRiver Ops（架空）」への初回ディスカバリー商談を準備し、その後のフォローアップメールとディール管理プランを作成する。
**入力項目：** 公開されている決算情報、業界動向、過去の接触履歴、自社製品の提供価値。
**成果物：** アカウント・ブリーフ、ディスカバリー用質問リスト、フォローアップメール、MAPドラフト。

### プロンプト・コレクション

1. 「このアカウントの直近の課題を、公開されている [資料名] から3つ抽出し、弊社の製品でどう解決できるか整理してください。」
2. 「この顧客との商談ログ（添付）から、まだ確認できていないBANT要素を特定し、次の商談で聞くべき質問を作ってください。」
3. 「商談での合意事項に基づき、顧客側のメリットを強調したリキャップメールを作成してください。」
4. 「ステークホルダー別の関心事を予測し、各キーマンへのアプローチ方法を提案してください。」
5. 「この提案内容に、現実離れした約束や、過去の失注要因となる表現がないかレビューしてください。」

## 実践記録テンプレート

> **活用アドバイス：** 記録を残す際は、AIが生成した仮説を商談でぶつけてみた結果、「何が当たっていて何が違ったか」というギャップを記録してください。

### 実践ログシート

| 記録項目 | 記入のヒント |
| --- | --- |
| **なぜ学んだか** | どの案件の準備効率や提案の質を向上させたかったか。 |
| **使用した入力の種類** | 顧客HP、プレスリリース、商談メモ、CRMの活動履歴など。 |
| **初回のプロンプト** | 顧客の痛みを深掘りさせるために出した指示。 |
| **出力のギャップ** | 業界知識が一般的すぎる、自社の強みと結びついていないなど。 |
| **修正のプロセス** | ターゲットの具体的な発言の追加、競合状況の補足、出力フォーマットの指定など。 |
| **最終的な成果物** | 実際に商談で使用し、顧客からの反応が良かった準備シートや提案構成案。 |
| **商談での検証結果** | AIが立てた仮説のうち、どれが顧客に刺さったか。 |
| **ナレッジの共有** | 「顧客の言葉をそのままプロンプトに入れると、共感を得やすいメールになる」といった知見。 |
