## まず一言で

プロンプト（Prompt）とは、AI に対する「依頼文」です。単なる質問だけでなく、AI の役割、タスクの目的、背景情報、使用すべき材料、守るべき制約、そして出力形式などを包括的に伝える指示のことを指します。

初心者のうちは、プロンプトを「結果を出すための魔法の呪文」のように捉えがちですが、その理解では AI の出力をコントロールし続けることは困難です。より実務的な視点では、プロンプトは AI との共同作業をスムーズに始めるための「ブリーフ（業務指示書）」であると考えるのが最適です。

## 優れたプロンプトを構成する要素

複雑なタスクほど、プロンプトは詳細な「仕様書」に近づきます。一般的に、以下の要素が含まれると精度が安定します。

| 要素 | 役割 | 例 |
| --- | --- | --- |
| **役割（Role）** | どの専門家の視点で考えるか | 「あなたは経験豊富なプロダクトマネージャーです」 |
| **目的（Goal）** | 何を完成させたいか | 「ブログ記事の導入文を作成したい」 |
| **背景（Context）** | 状況や想定読者を伝える | 「読者は AI 初心者で、専門用語を避けたい」 |
| **材料（Input）** | 参照すべき具体的な情報 | 「以下の箇条書きを元に文章化してください」 |
| **制約（Constraint）** | 避けるべきこと、守るべきトーン | 「300 文字以内。営業的な表現は使わない」 |
| **形式（Output）** | 回答の形を指定する | 「5 つの見出しを持つ Markdown 形式で出力」 |

## そのまま使える汎用テンプレート

以下の構成で依頼すると、AI の回答精度が格段に向上します。

```text
【目的】[何をしたいか]
【背景】[現在の状況、ターゲット、すでにある材料]
【タスク内容】[AI に具体的にお願いしたい作業]
【制約事項】[トーン、文字数、避けたい表現]
【出力形式】[箇条書き、表、JSON、ドラフト、手順書]

※もし情報が不足している場合は、作業を開始する前に確認すべき質問を箇条書きで出してください。
```

テンプレートは「魔法」ではありません。プロンプトが上手い人とは、特別な言葉を知っている人ではなく、**「タスクを適切に分解し、相手（AI）に必要な情報を過不足なく伝えられる人」**のことです。

## プロンプトが期待通りにいかない理由

多くの場合、AI の能力不足ではなく、依頼（プロンプト）の曖昧さが原因です。

- 「いい感じにして」といった、目的が広すぎる指示。
- ターゲットや利用シーンが定義されていない。
- 最終的にどのような形式で受け取りたいかが指定されていない。
- 何をもって「良い成果物」とするかの評価基準がない。
- 一つのプロンプトに複数の異なるタスクを詰め込みすぎている。

## やってみよう：実践ワーク

上記のテンプレートを使って、今週の実際の業務で使えるプロンプトを 1 つ作成してみてください。

**例：クライアントへの返信メール案**
```text
【目的】打ち合わせ日程の調整メール
【背景】先方から価格の問い合わせがあり、一度 Web 会議で詳細を説明したい。
【タスク】丁寧だが簡潔な返信メールのドラフトを作成。
【制約】押し売り感を出さず、相手の都合を優先する姿勢を見せる。
【出力形式】メールの件名と本文のみ。
※不足している情報があれば先に聞いてください。
```

テンプレートの項目を自分の状況に置き換えて、ChatGPT や Claude に入力してみましょう。

## 実用的な見方

AI の回答が思わしくなかったときは、モデルを変更する前に以下の 3 点を確認してください。

1. **「目的」は具体的か？**
2. **十分な「背景（Context）」を渡したか？**
3. **「どのような出力」なら合格点かを伝えたか？**

これらを意識するだけで、プロンプトによる試行錯誤の回数を劇的に減らすことができます。
